A bootstrapper is a single-method struct that performs one initialization step during application boot. They run sequentially; each one can rely on everything the preceding ones
registered. The boot sequence halts on the first error.

## The Interface

```go [pkg/foundation/bootstrapper.go]
type Bootstrapper interface {
    Bootstrap(app *Application) error
}
```

## Default Boot Sequence

Eight bootstrappers run in this exact order:

| Step | Bootstrapper           | What It Does                                               | Why Here                          |
|------|------------------------|------------------------------------------------------------|-----------------------------------|
| 1    | `EnsureDirectories`    | Creates `.tako/run/`                                       | Internal framework directory      |
| 2    | `RegisterLogger`       | Opens `tako.log`; registers close on destroy               | Everything after needs logging    |
| 3    | `RegisterStorage`      | Opens `kv.db`; registers flush+close on destroy            | Degrades gracefully if unwritable |
| 4    | `RegisterProfiler`     | No-op unless `TAKO_PROFILER_ENABLED=true`                  | Zero cost in production           |
| 5    | `LoadConfiguration`    | Merges `config/*.yaml` and `config/*.json`                 | Providers read config in Boot     |
| 6    | `RegisterCoreCommands` | Registers `help`, `version`, `status`, `plugin:list`, etc. | CLI needs config + storage        |
| 7    | **`BootProviders`**    | Validates dependencies → boots providers in order          | Providers need everything above   |
| 8    | `RecordMetrics`        | Records total boot time to profiler                        | Must be last                      |

### BootProviders in Detail

`BootProviders` is the bridge between the bootstrapper system and the ServiceProvider system:

1. **Validate** — Checks `DependsOn` declarations. If Provider X requires "DatabaseProvider" but it's not registered → error with clear message.
2. **Mark booted** — Sets `app.isBooted = true`. Dynamic registrations after this point get deferred boot.
3. **Boot** — Calls `Boot()` on each provider in registration order.
4. **Pending** — Boots any providers that were dynamically registered during the Boot phase.

```go [pkg/foundation/bootstrap/providers.go]
func (b *BootProviders) Bootstrap(app *foundation.Application) error {
    // Validate DependsOn declarations
    for _, p := range app.GetProviders() {
        if dep, ok := p.(foundation.DependsOn); ok {
            for _, need := range dep.Dependencies() {
                if !app.IsRegistered(need) {
                    return fmt.Errorf("provider %T requires %q to be registered first", p, need)
                }
            }
        }
    }

    app.MarkAsBooted()

    for _, p := range app.GetProviders() {
        if err := p.Boot(app); err != nil {
            return fmt.Errorf("boot %T: %w", p, err)
        }
    }

    return app.BootPending()
}
```

## Writing a Custom Bootstrapper

```go [bootstrap/websocket.go]
type RegisterWebSocket struct{}

func (b *RegisterWebSocket) Bootstrap(app *foundation.Application) error {
    endpoint := app.Config().String("websocket.endpoint")
    if endpoint == "" {
        app.Logger().Warn("WebSocket endpoint not configured, skipping")
        return nil
    }

    client, err := NewWebSocketClient(endpoint)
    if err != nil {
        return fmt.Errorf("WebSocket connection failed: %w", err)
    }

    app.Container().Singleton((*contracts.WSClient)(nil), client)
    app.OnDestroy(func() { client.Unmount() })

    return nil
}
```

Key patterns:

- **Log + return nil** for soft failures (missing config)
- **Return an error** for hard failures (broken connection)
- **Register `OnDestroy`** for resources that need cleanup
- **Bind against interfaces**, not concrete types

## Customizing the Boot Sequence

```go [main.go]
func main() {
    app := foundation.NewApplication()

    app.RegisterProviders(
        &providers.AppProvider{},
    )

    bootstrappers := append(
        bootstrap.DefaultBootstrappers(),
        &myboot.RegisterWebSocket{},
        &myboot.RegisterAnalytics{},
    )

    if err := app.BootstrapWith(bootstrappers); err != nil {
        panic(err)
    }
}
```

**Ordering constraint:** If bootstrapper B resolves a service registered by bootstrapper A, A must come before B.

## Testing with Selective Bootstrap

```go [app_test.go]
func TestFeature(t *testing.T) {
    app := foundation.NewApplication()

    // Boot only what this test needs
    err := app.BootstrapWith([]foundation.Bootstrapper{
        &bootstrap.RegisterLogger{},
        &bootstrap.LoadConfiguration{},
        &bootstrap.BootProviders{},
    })
    require.NoError(t, err)
}
```
