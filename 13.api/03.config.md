<a name="LoadConfigDirectory"></a>
### func [LoadConfigDirectory](<https://github.com/gettako/tako/blob/main/internal/config/config.go#L28>)

```go [config.go]
func LoadConfigDirectory(dirPath string) (*MapConfig, error)
```

LoadConfigDirectory scans a directory for `*.yaml`, `*.yml`, and `*.json` files, parses each one, and injects the file's basename as the root prefix. For example, `config/database.yaml` with key `host` becomes accessible as `database.host`.

If the directory does not exist, it is automatically created (scaffolding) and an empty config is returned.
