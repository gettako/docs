# Dynamic Registration

A provider can register other providers from within its `Register` or `Boot` method. This enables **feature groups** — one provider that assembles multiple sub-features.

## In Register Phase

Sub-providers join the normal boot sequence:

```go
type EcommerceProvider struct{}

func (p *EcommerceProvider) Register(app *foundation.Application) error {
    return app.RegisterProviders(
        &CartProvider{},
        &CheckoutProvider{},
        &InventoryProvider{},
    )
}

func (p *EcommerceProvider) Boot(app *foundation.Application) error { return nil }
```

Consumer sees one provider in `main.go`:

```go
app.RegisterProviders(
    &providers.DatabaseProvider{},
    &ecommerce.EcommerceProvider{}, // internally registers 3 sub-providers
)
```

## In Boot Phase

Sub-providers registered during Boot are handled safely:

1. `Register()` called immediately
2. `Boot()` **deferred** to a pending batch
3. Pending batch boots after all initial providers finish

This prevents race conditions.

```go
func (p *PluginLoaderProvider) Boot(app *foundation.Application) error {
    for _, name := range app.Config().StringSlice("plugins.enabled") {
        plugin := loadPlugin(name)
        app.RegisterProviders(plugin) // Register now, Boot deferred
    }
    return nil
}
```

## Conditional Registration

Feature flags via dynamic registration:

```go
func (p *AppProvider) Register(app *foundation.Application) error {
    providers := []foundation.ServiceProvider{
        &CoreProvider{},
        &AuthProvider{},
    }
    if os.Getenv("ENABLE_ANALYTICS") == "true" {
        providers = append(providers, &AnalyticsProvider{})
    }
    return app.RegisterProviders(providers...)
}
```

## Testing

Register only what the test needs:

```go
func TestCheckout(t *testing.T) {
    app := foundation.NewApplication()
    app.RegisterProviders(&FakeDB{}, &CheckoutProvider{})
    bootstrap.Boot(app)
    // test in isolation
}
```
