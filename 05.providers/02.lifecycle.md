# Two-Phase Lifecycle

The lifecycle solves a fundamental problem: **how do you guarantee Service A is available when Service B needs it?**

Split initialization into binding (`Register`) and execution (`Boot`). All bindings complete before any execution starts.

```mermaid
sequenceDiagram
    participant App as Application
    participant P1 as Provider 1 (Database)
    participant P2 as Provider 2 (API)

    box rgba(100, 150, 255, 0.1) Phase 1: Register (Bind Only)
    App->>P1: Register()
    P1-->>App: Bind DB Service to Container
    App->>P2: Register()
    P2-->>App: Bind API Service to Container
    end

    box rgba(100, 255, 150, 0.1) Phase 2: Boot (Execute Freely)
    App->>P1: Boot()
    P1-->>App: Open Database Connection
    App->>P2: Boot()
    P2-->>App: Fetch Initial Data
    end
```

## Register — Bind Only

Called immediately when `app.RegisterProviders(...)` is invoked.

| ✅ Do                         | ❌ Don't                 |
|------------------------------|-------------------------|
| `Container().Singleton(...)` | `Container().Make(...)` |
| `Container().Lazy(...)`      | Access Config, Logger   |
| `app.RegisterProviders(...)` | Start goroutines        |
| Pure computation             | Network/file I/O        |

```go
func (p *CacheProvider) Register(app *foundation.Application) error {
    app.Container().Lazy((*cache.Store)(nil), func() (any, error) {
        return cache.New(app.Config().String("cache.driver", "memory"))
    })
    return nil
}
```

## Boot — Execute Freely

Called after ALL providers have completed Register. Resolve anything with confidence.

```go
func (p *CacheProvider) Boot(app *foundation.Application) error {
    var store *cache.Store
    app.Make(&store) // guaranteed available

    app.Events().Subscribe(app.Context(), "cache:flush", func(e contracts.Event) {
        store.Flush()
    })
    return nil
}
```

### Common Patterns

**Register keybindings:**

```go
func (p *AppProvider) Boot(app *foundation.Application) error {
    app.Keys().Bind("ctrl+r", func() { /* refresh */ })
    return nil
}
```

**Background work:**

```go
func (p *SyncProvider) Boot(app *foundation.Application) error {
    go func() {
        ticker := time.NewTicker(30 * time.Second)
        defer ticker.Stop()
        for {
            select {
            case <-app.Context().Done():
                return
            case <-ticker.C:
                p.sync()
            }
        }
    }()
    return nil
}
```

**Show UI:**

```go
func (p *DashboardProvider) Boot(app *foundation.Application) error {
    app.Stack().Push("base")
    var om contracts.UIManager
    app.Make(&om)
    om.MountOverlay(&DashboardView{})
    return nil
}
```

## Shutdown (Optional)

Implement `Disposable` for cleanup. Called in **LIFO order** during `app.Shutdown()`:

```go
type Disposable interface {
    Shutdown() error
}
```

```go
type DatabaseProvider struct{ db *sql.DB }

func (p *DatabaseProvider) Shutdown() error {
    return p.db.Unmount()
}
```

## Error Handling

- `Register` error → boot halts, no provider is partially initialized
- `Boot` error → clear message: `boot *DatabaseProvider: connection refused`
- `Boot` panic → recovered with stack trace, reported as error

## Safety Guarantees

| Issue                   | Protection                                    |
|-------------------------|-----------------------------------------------|
| Panic in Boot           | Recovered per-provider with stack trace       |
| Panic in Shutdown       | Each provider isolated — others still cleanup |
| Duplicate registration  | Error on second attempt                       |
| Double shutdown         | `sync.Once` — safe to call multiple times     |
| Concurrent registration | Mutex-protected                               |
| Infinite dynamic loop   | Capped at 16 iterations                       |
