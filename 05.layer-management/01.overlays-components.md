## The Overlay Manager

All high-level layer management goes through a single entry point: the `OverlayManager`.

```go [lifecycle.go]
app.Overlay()                     // In host app
ctx.Overlay()                     // In plugins
```

This manager provides methods for handling **basic overlays**, **stateful components**, and **dialog primitives**.

## Basic Overlays

For simple views that don't need their own isolated state or keybindings, you can use basic overlays.

### Showing an Overlay
`Show(layerID string, render func() any)`

Pushes the given ID onto the focus stack, registers the render function, and shifts keyboard focus to the new layer.

```go [lifecycle.go]
ctx.Overlay().Show("help", func() any {
    return p.renderHelpView()
})
```
Your layout reads the render output via the hook `"tako.overlay.help"`.

### Closing Overlays
- `Close()`: Pops the topmost overlay and reverts focus to the layer below.
- `CloseAll()`: Pops every overlay down to the base layer.
- `Top()`: Returns the ID of the currently active overlay.
- `IsActive()`: Reports whether any overlay is currently shown.

## Stateful Components

A `Component` bundles a UI view and its keybindings into a single, self-describing struct. Instead of scattering hook registration and key bindings across your plugin's init method, a Component declares everything about itself in one place.

### Defining a Component

Implement the `contracts.Component` interface:

```go [component.go]
type SearchBox struct {
    query string
}

// 1. ID is used as the layer ID and the default zone name.
func (s *SearchBox) ID() string { return "search" }

// 2. Render returns the view output.
func (s *SearchBox) Render() any {
    return "Search: [" + s.query + "]"
}

// 3. RegisterKeys declares the component's keybindings.
func (s *SearchBox) RegisterKeys(keys contracts.KeyManager) {
    keys.Zone(s.ID()).Bind("esc", func() {
        // The OverlayManager will close this layer automatically via global esc (usually).
    })
    
    keys.Zone(s.ID()).Bind("enter", func() {
        // handle confirm
    })
}
```

Because a Component is just a struct, you can instantiate it multiple times with different states (e.g., passing different callbacks or properties on initialization).

### Showing a Component

To display the component, use `ShowComponent`:

```go [lifecycle.go]
ctx.Keys().Bind("ctrl+f", func() {
    ctx.Overlay().ShowComponent(&SearchBox{})
})
```

`ShowComponent()` does three things automatically:
1. Registers the render hook under `"tako.overlay.<id>"`.
2. Calls `RegisterKeys()` at the correct stack level.
3. Calls `Overlay().Show()` to push the layer and shift focus.

If you need to pre-register a component's hooks and keys without pushing it to the stack immediately, use `ctx.Overlay().Register(c)`.

## Accessing Dialogs

Dialogs (Confirm, Prompt, etc.) are just a specific type of overlay. To keep the `OverlayManager`'s interface clean, they are grouped under the `Dialog()` sub-namespace.

```go [lifecycle.go]
app.Overlay().Dialog().Confirm("Delete?", func(yes bool) { ... })
```

For more details on Dialogs, proceed to the [Dialogs](./dialogs) documentation.
