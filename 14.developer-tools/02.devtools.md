Time Travel lets you debug the past; DevTools lets you debug the present. It's an interactive inspector that connects to your running application and streams live diagnostics.
Think of it as Chrome DevTools for your terminal app.

## Launching DevTools

Open a second terminal window and run:

```bash [terminal]
go run . inspect
```

The inspector discovers your running Tako process automatically, authenticates, and opens an interactive dashboard that refreshes every 500ms.

::tip
Run your app in one terminal, and `go run . inspect` in another. No configuration needed.
::

## What's Inside

### Health Metrics

Track frames per second (FPS), average update/render times, heap allocations, active goroutines, background scheduler jobs, and event bus throughput.

### Boot Performance

See the initialization times for the framework, the total bootstrap sequence, and the DAG resolution time for all providers.

### Live Event Stream

Watch every event flowing through the event bus in real-time. This confirms that `Emit` calls fire and payloads are correct.

### Focus Stack & Keybindings

See the active focus stack, which zone holds focus, and a table of all registered keybindings mapped to their respective handlers and zones.

## Architecture

During bootstrap, Tako starts a lightweight WebSocket server on a random loopback port (`127.0.0.1:0`). A PID file at `.tako/run/<pid>.json` stores the port and a one-time auth
token. The `inspect` command reads this file, connects via WebSocket, and renders the JSON payloads.

- **Loopback only**: The server binds to `127.0.0.1` and is never network-accessible.
- **Token auth**: A unique UUID v4 secures the session.
- **Cleanup**: Stale PID files from crashed processes are pruned on startup.

## Production Usage

DevTools only starts when `TAKO_PROFILER_ENABLED=true` or when running via `go run`.

```bash [terminal]
TAKO_PROFILER_ENABLED=true ./myapp &
./myapp inspect
```

::caution
Only enable the profiler temporarily in production. It consumes additional memory for metric buffers, and the WebSocket server exposes internal state.
::
