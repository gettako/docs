When something goes wrong in a TUI application, the hardest question is always "what happened before that?" You can't set breakpoints in a running terminal UI. You can't scroll
back through stdout. Time Travel solves this by recording every event flowing through your application, then letting you replay the entire session as an interactive, step-through
debugging experience — like a VCR for your app's internal state.

## Recording a Session

There are two ways to enable trace recording for your application:

### 1. Dev Mode (Recommended)

When working in hot-reload mode, pass the `--trace` (or `-t`) flag. The Dev watcher will automatically inject the required environment variables into the child process.

```bash [terminal]
go run . dev -t
```

### 2. Manual Execution

If you are running the application manually, enable recording by setting an environment variable before launching:

```bash [terminal]
TAKO_RECORD_TRACE=1 go run .
```

Tako captures every event to `.tako/traces/trace-<timestamp>.jsonl`. Reproduce the bug, gracefully exit the app (`ctrl+c`), and your trace file is ready.

### Configuration

For finer control, configure the recorder programmatically during bootstrap:

```go [providers/debug/provider.go]
func (p *Provider) Boot(app *foundation.Application) error {
    var rec contracts.Recorder
    app.Container().Make(&rec)

    rec.Path(".tako/traces")
    rec.MaxFileSize(50 * 1024 * 1024)
    rec.MaskFields("password", "token", "secret")
    rec.IncludeEvents("state:", "order:")
    rec.ExcludeEvents("scheduler:")
    rec.Compress(true)
    rec.Start(app.Context())
    return nil
}
```

::tip
Use `MaskFields` to recursively redact sensitive keys from payloads so credentials never hit the disk.
::

## Replaying a Session

Launch the interactive Time Travel player:

```bash [terminal]
go run . replay
```

This automatically opens the most recent trace file. To replay a specific file:

```bash [terminal]
go run . replay .tako/traces/trace-1718123456.jsonl
```

### The Replay Interface

The player is a full TUI with these controls:

| Key       | Action                                    |
|-----------|-------------------------------------------|
| `Space`   | Play / Pause                              |
| `→` / `←` | Step forward / backward one event         |
| `1`-`4`   | Speed: 1x / 2x / 4x / 100x (fast-forward) |
| `g`       | Jump to specific event number             |
| `f`       | Filter events by name                     |
| `n` / `p` | Next / Previous matching filter           |
| `d`       | Toggle state diff view                    |
| `r`       | Restart from beginning                    |

### State Reconstruction

As the player steps through events, it reconstructs your application's state tree in real-time. With diff view enabled (`d`), you see exactly which keys changed at each step —
highlighted with before/after values.

The player uses periodic snapshots (every 100 events) for efficient backward navigation, allowing instant jumps without replaying from the beginning.

## Trace File Format

Traces are JSONL files (one JSON object per line):

```json [.tako/traces/trace-1718123456.jsonl]
{"time":1718123456000000000,"event":"state:changed","payload":{"key":"cart.items","value":["SKU-001"]}}
{"time":1718123456100000000,"event":"order:created","payload":{"id":"ORD-42","total":99.99}}
```

Each entry contains the nanosecond timestamp, event name, and the arbitrary JSON payload (with masked fields redacted).
