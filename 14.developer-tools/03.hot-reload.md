The traditional edit → save → ctrl+c → `go run .` cycle breaks focus. Tako's `dev` command watches your source files and automatically rebuilds and restarts your app when something
changes.

## Usage

```bash [terminal]
go run . dev
```

Tako watches your project directory, rebuilds on changes, and restarts the process. The first build happens immediately.

### Custom Watch Parameters

```bash [terminal]
go run . dev --include .go,.yaml --exclude _test.go --debounce 500
```

## How It Works

The watcher recursively monitors your project using `fsnotify`:

1. **File change detected**: Any write to a watched file triggers the pipeline.
2. **Debounce (300ms)**: Batches rapid saves (like editor auto-formatting) into a single rebuild.
3. **Rebuild**: Runs `go build` on your entry point.
4. **Restart**: Kills the old process and launches the new binary.

## What Gets Watched

By default, the watcher includes:

- All `.go` files recursively
- The `config/` directory (YAML/JSON changes trigger restarts)

It automatically ignores:

- Hidden directories (`.git`, `.tako`)
- The `vendor/` directory
- Editor temp files (`~`, `.swp`, `.tmp`)

If you create a new directory while `dev` is running, the watcher automatically adds it to the list. No restart needed.

::tip
Pair `dev` with Time Travel (`TAKO_RECORD_TRACE=1 go run . dev`) to automatically capture traces of every restart cycle.
::
