# Tako Cheat Sheet

This is a quick reference guide for the methods and syntax in the Tako Framework.

## Application Initialization

```go
app := tako.NewApp()

app.
    WithProviders(&MyProvider{}).
    WithMiddleware(MyGlobalMiddleware).
    WithUIAdapter(adapter.NewBubbleteaAdapter()).
    WithDefaultCommand("tui:start").
    BootstrapWith(func() {
        app.Logger().Info("Application successfully booted!")
    })
```

## Context Shortcuts

The `contracts.Context` is your primary, thread-safe access point inside all handlers and components.

| Action | Elegant Syntax |
|---|---|
| Force UI Render | `ctx.RenderNow()` |
| Safely Navigate | `ctx.Router().GoTo("route.name")` |
| Emit Event | `ctx.Events().Dispatch("user.login").Fire()` |
| Read Config | `ctx.Config().GetString("app.name", "Fallback")` |
| Read State | `ctx.State().Get("user.token")` |
| Write State | `ctx.State().Mutate("key").Value("val").Broadcast()` |

## IoC Container

```go
// Singleton Binding
app.Container().Singleton(new(MyInterface), &MyImplementation{})

// Lazy Binding (Recommended for Performance)
app.Container().Lazy(new(ExpensiveService), func() (any, error) {
    return InitService(), nil
})

// Resolve Safely
var service MyInterface
app.Make(&service)

// Auto-inject Elegantly via Call
app.Call(func(logger contracts.Logger, s MyInterface) {
    logger.Info("Injected!")
})
```

## Routing

```go
router := app.Router()

// Basic Route
router.Route("/login", components.NewLogin()).Name("login")

// Protected Route (Middleware)
router.Route("/admin", components.NewAdmin()).Name("admin").Use(AuthMiddleware)

// Shared Layout Shell
router.Root(adminLayout, func(r contracts.Router) {
    r.Route("/dashboard", components.NewDash()).Name("dash")
})

// Isolated Scopes
router.Scope("/api").Use(ApiLogger).Root(nil, func(r contracts.Router) {
    r.Route("/users", components.NewUsers()).Name("api.users")
})
```

## Event Dispatcher

```go
// Fluent Dispatch with Payload and Exact Delay
ctx.Events().
    Dispatch("email.send").
    WithPayload("user@example.com").
    Delay(2 * time.Second).
    Fire()
```

## Storage

```go
// Write plain data
ctx.Storage().Put("key", []byte("data"))

// Write securely encrypted data
ctx.Storage().SecurePut("secret_key", []byte("password"))

// Read data
val, _ := ctx.Storage().Get("key")
```
