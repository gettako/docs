Modern terminal emulators support mouse interactions like clicking, scrolling, and dragging. However, because the terminal is essentially a grid of text characters—lacking a Document Object Model (DOM) like a web browser—tracking exactly *which* component was clicked based on an X/Y coordinate is a complex calculation.

Tako abstracts this complexity using the **Mouse Registry**.

## Enabling Mouse Support

Mouse tracking can be powerful, but it must be explicitly enabled at the application level so Tako knows to ask the terminal emulator for mouse telemetry. You can do this via your configuration:

```yaml [config/app.yml]
ui:
  mouse: true
```

Or programmatically inside a Service Provider:

```go
app.UI().EnableMouse(true)
```

## Handling Mouse Events

Unlike keybindings that are attached via `Keys()`, mouse events operate slightly differently because components can move around the screen dynamically. Tako provides a `MouseRegistry` accessible directly from the Context or Application.

You register a coordinate zone (a bounding box) and bind it to a callback. Tako handles the hit-detection math for you.

```go
func (c *ButtonComponent) Init(ctx contracts.Context) {
    // Assuming our button renders at column 10, row 5, with a width of 12 and height of 3
    zone := contracts.Zone{
        X: 10,
        Y: 5,
        Width: 12,
        Height: 3,
    }

    // Register the hit zone
    ctx.Application().Mouse().RegisterZone(c.ID(), zone, func(event contracts.MouseEvent) {
        if event.Action == contracts.MouseLeftClick {
            ctx.Logger().Info("Button was clicked!")
            
            // Do something and signal a redraw
            ctx.RenderNow()
        }
    })
}
```

## Mouse Scrolling

Scrolling is the most common use-case for mouse support in TUIs, particularly for navigating long lists, tables, or application logs.

The `MouseEvent` struct contains the information you need about the scroll wheel:

```go
func (c *LogViewer) Init(ctx contracts.Context) {
    ctx.Application().Mouse().OnGlobalScroll(func(event contracts.MouseEvent) {
        if event.Action == contracts.MouseWheelUp {
            c.ScrollUp()
        } else if event.Action == contracts.MouseWheelDown {
            c.ScrollDown()
        }
        
        ctx.RenderNow()
    })
}
```

::warning
Mouse support varies across different terminal emulators (e.g., iTerm2 vs Alacritty vs Windows Terminal). While Tako handles the inputs, you should ensure your application can be fully navigated using keyboard shortcuts as a fallback.
::
