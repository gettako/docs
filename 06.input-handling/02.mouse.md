Handling mouse input in standard terminal applications is notoriously difficult because terminals are character-based grids, not pixel-based screens. Tracking exactly *where* a user clicked requires complex coordinate mapping.

Tako solves this by deeply integrating with [BubbleZone](https://github.com/lrstanley/bubblezone) and wrapping it in an elegant, easy-to-use **Mouse Manager**.

## Enabling Mouse Support

To use mouse interactions in your Tako application, you must first enable Mouse support in your Bubble Tea program. The TUI Kernel handles this automatically, but you must ensure your terminal emulator actually supports mouse reporting.

## The Mouse Manager

You can access the Mouse Manager through the Input Manager (`km.Mouse()`). The Mouse Manager allows you to bind closures to specific mouse actions (like clicking or scrolling), just like you would for keyboard shortcuts.

### Global Mouse Actions

If you want to track scrolling or clicking anywhere on the screen (regardless of what is being clicked), you can use global handlers. 

```go
func (s *ListScreen) Keys(km contracts.InputManager) {
	mouse := km.Mouse()

	mouse.OnScrollUp(func(ctx contracts.MouseContext) {
		// User scrolled up anywhere on the screen
		s.cursor--
	})

	mouse.OnScrollDown(func(ctx contracts.MouseContext) {
		// User scrolled down anywhere on the screen
		s.cursor++
	})
}
```

### The Mouse Context

Similar to the `InputContext`, mouse handlers receive a `contracts.MouseContext`. This context provides details about the exact location and type of mouse interaction.

```go
mouse.OnClick(func(ctx contracts.MouseContext) {
	x := ctx.X()
	y := ctx.Y()
	button := ctx.Button() // "left", "right", "middle"

	app.Logger().Debug(fmt.Sprintf("User clicked %s at X:%d, Y:%d", button, x, y))
})
```

## Mapping Mouse to Keys (Shortcuts)

A very common pattern in TUI applications is to map mouse scrolls directly to keyboard arrows. For example, scrolling up with the mouse wheel should do the exact same thing as pressing the `up` arrow key.

Tako provides helpful shortcut methods to automatically proxy mouse actions to your existing keybindings!

```go
func (s *MenuScreen) Keys(km contracts.InputManager) {
	// First, define your keyboard shortcuts
	km.Bind("up", func(ctx contracts.InputContext) { s.MoveUp() })
	km.Bind("down", func(ctx contracts.InputContext) { s.MoveDown() })

	// Then, magically map mouse scrolls to trigger those same keys!
	km.Mouse().MapScrollToKeys("up", "down")
}
```

This saves you from having to write duplicate logic for mouse scrolling and keyboard navigation.

## Clickable Zones (Buttons)

The most powerful feature of the Mouse Manager is handling clicks on specific text elements (like buttons or links). 

Tako uses **Zones** to achieve this. A Zone is simply an ID attached to a string of text during rendering. When the user clicks on the screen, Tako checks if the click coordinates fall within the boundaries of that Zone.

### 1. Rendering the Zone

First, you wrap a piece of text with `zone.Mark(id, text)` inside your `Render` method:

```go
import "github.com/lrstanley/bubblezone/v2"

func (s *ButtonScreen) Render(ctx contracts.Context) string {
	button := zone.Mark("submit_button", "[ Submit Form ]")
	
	return "Please click here: \n\n" + button
}
```

### 2. Handling the Click

Then, you register a listener for that specific Zone ID using `OnZoneClick`:

```go
func (s *ButtonScreen) Keys(km contracts.InputManager) {
	km.Mouse().OnZoneClick("submit_button", func(ctx contracts.MouseContext) {
		// This will ONLY execute if the user clicked exactly on "[ Submit Form ]"
		ctx.Router().Navigate("success")
	})
}
```

This combination completely abstracts the nightmare of terminal coordinate math, allowing you to build rich, clickable, interactive interfaces with ease!
