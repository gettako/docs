## Provider Won't Boot

**Symptom:** Your provider's `Boot` never runs, or you see "Provider X failed to boot" in the logs.

**Causes:**

- **Missing registration in `main.go`**: Providers must be registered explicitly:
   ```go [main.go]
   app.RegisterProviders(&search.SearchProvider{})
   ```
- **Dependency not registered**: A `Dependencies()` declaration references a provider that doesn't exist. Run `go run . plugin:list` to check.
- **Panic during boot**: Check `.tako/logs/tako.log` for stack traces. Panics inside provider methods are caught and logged, not propagated to crash the app.

## Key Not Responding

**Symptom:** You registered a keybinding but pressing it does nothing.

**Causes:**

- **Bound to an inactive zone**: If focus is elsewhere, zone-scoped keys are ignored. Run `go run . route:list` to see bindings and focus status.
- **Overlay is stealing focus**: Only the top stack level receives input. Close the overlay or register the key as global.
- **Key normalization mismatch**: Tako normalizes keys (e.g., `Escape` → `esc`, `Ctrl-Q` → `ctrl+q`). Ensure your registration uses the normalized format.

## State Observer Not Firing

**Symptom:** You called `Watch(...).Subscribe(...)` but the callback never fires.

**Causes:**

- **Wrong context**: Passing a cancelled context kills the subscription immediately. Use the provider's context, not `context.Background()`.
- **Key mismatch**: State keys are case-sensitive. `"Cart.Total"` is not `"cart.total"`.
- **Debounce hiding updates**: A long debounce window batches rapid changes. The callback fires after the window closes, not immediately.

## DevTools Shows 0 FPS

**Symptom:** `go run . inspect` connects but performance metrics show zero.

**Causes:**

- **Profiler not initialized**: Call `InitProfiler()` inside your adapter's render loop, after boot completes.
- **Missing timing calls**: The profiler requires your adapter to report timing using `RecordUpdate` and `RecordView`. See [Profiler Integration](/extending/profiler-integration).
- **Running in production**: The profiler is disabled by default unless `TAKO_PROFILER_ENABLED=true` or you're running via `go run`.

## Config Values Always Empty

**Symptom:** `ctx.Config().String("app.name")` returns `""` despite the file existing.

**Causes:**

- **Wrong directory**: Config files must be in the `config/` directory relative to your working directory.
- **Syntax error**: Unparseable YAML files are silently skipped. Validate with `go run . config:dump`.
- **Key case**: Config keys are lowercased internally (`App.Name` becomes `app.name`).
- **Missing prefix**: The filename is the prefix (`app.yaml` means keys are `app.key`, not `key`).

## Stack Pop Blocked

**Symptom:** Calling `Pop()` does nothing; the overlay remains open.

**Cause:** A `BeforePop` guard is preventing it. If you registered a guard that returns `false`, the pop is aborted.

```go
ctx.Stack().OnPopBlocked(func(layer, reason string) {
    ctx.Logger().Warn("pop blocked", "layer", layer, "reason", reason)
})
```

## Hot Reload Not Detecting Changes

**Symptom:** `go run . dev` doesn't rebuild when you save files.

**Causes:**

- **Wrong file extension**: By default, only `.go` files trigger rebuilds.
- **Hidden directory**: `.git/` and `.tako/` are excluded.
- **Atomic saves**: Some editors write to a temp file and rename it. If the watcher misses it, try saving again.

## Cron Job Never Fires

**Symptom:** You registered `ctx.Jobs().Cron(...)` but the callback is never executed.

**Causes:**

- **Unchecked Error**: The cron expression is parsed immediately. If you pass an invalid expression (e.g., `60 * * * *`) and ignore the returned `err`, the job will silently fail
  to schedule. Always handle the error.
- **Timezone Expectations**: Tako's built-in cron uses the machine's local timezone. If your server runs in UTC but you expect WIB (UTC+7), your jobs will fire 7 hours late.

## Contextual Logger Not Working

**Symptom:** You called `ctx.Logger().With("foo", "bar")` but subsequent logs don't show the `foo` key.

**Cause:** `With` and `WithGroup` do not mutate the logger in-place. They return a **new** child logger instance. You must use the returned instance:

```go
// Wrong:
ctx.Logger().With("foo", "bar")
ctx.Logger().Info("hello") // "foo" is missing

// Correct:
log := ctx.Logger().With("foo", "bar")
log.Info("hello") // "foo" is present
```

## Generic Resolve Panics

**Symptom:** Your application crashes with `tako: MustResolve failed: no implementation registered for...`.

**Cause:** You used `tako.MustResolve[T]` for a service that hasn't been registered in the IoC container. `MustResolve` is designed to panic for missing architecturally-guaranteed
bindings. If a service is optional or might fail to resolve, use `tako.Resolve[T]` instead and handle the returned error.
