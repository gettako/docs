# Troubleshooting

If you encounter unexpected behavior while building your Tako application, consult this guide for common symptoms and their resolutions.

## 1. Application Panics on Boot

**Symptom:**
You run `go run main.go` and the application immediately crashes with a `panic: invalid memory address or nil pointer dereference`.

**Cause:**
You are likely trying to resolve a service (e.g., `app.Router()`) before it has been registered, or you are calling `app.Make()` inside a Provider's `Register()` method instead of its `Boot()` method.

**Fix:**
Ensure that dependencies are only resolved inside the `Boot()` phase of your Service Providers, or inside the `BootstrapWith(func())` closure.

## 2. Unresponsive UI / Frozen Terminal

**Symptom:**
The TUI renders fine, but when you press a key or an event fires, the entire interface freezes.

**Cause:**
You are performing a synchronous, blocking operation (like a long HTTP request or a slow database query) directly inside your `Render()` loop or a synchronous Event Handler. Because the UI Adapter runs on a single main thread, blocking it prevents any further frames from drawing.

**Fix:**
Move blocking operations to a background goroutine. When the operation finishes, dispatch an event or mutate the global state, and then call `ctx.RenderNow()`.

```go
// BAD: Freezes the UI
func (c *MyComp) Keys(km contracts.KeyManager) {
    km.On("enter", "Fetch Data", func() {
        data := FetchFromSlowAPI() // Blocks!
        c.data = data
        c.app.RenderNow()
    })
}

// GOOD: Non-blocking
func (c *MyComp) Keys(km contracts.KeyManager) {
    km.On("enter", "Fetch Data", func() {
        go func() {
            data := FetchFromSlowAPI()
            c.app.Events().Dispatch("data.ready").WithPayload(data).Fire()
        }()
    })
}
```

## 3. Storage / Database Files Disappearing

**Symptom:**
You saved data to SQLite or `app.Storage()`, but after compiling your application to a binary, the data seems to be gone.

**Cause:**
You are experiencing Tako's Dual-Dimension path handling. When you run `go run main.go`, files are saved in `.tako/`. When you compile and run `./binary`, files are saved in `~/.app-name/`.

**Fix:**
This is intended behavior to separate development and production environments. If you want to force the binary to use the local development folder for debugging, set the environment variable `TAKO_DATA_DIR=.tako/`.

## 4. UI Does Not Update

**Symptom:**
You updated your component's internal struct (e.g., `c.count++`), but the number on the screen hasn't changed.

**Cause:**
Tako components do not watch their own fields. The UI Adapter has no idea that `c.count` changed.

**Fix:**
You must explicitly call `ctx.RenderNow()` to trigger a redraw after mutating your data.

## 5. Middleware Not Firing

**Symptom:**
You attached an `AuthMiddleware`, but users are still able to navigate to the protected route.

**Cause:**
You likely attached the middleware to a Router Scope, but defined the route *outside* of that scope's closure.

**Fix:**
Ensure your protected routes are strictly defined inside the `func(r contracts.Router)` block of the scoped router.
