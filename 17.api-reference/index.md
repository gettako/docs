## func [Bind](<https://github.com/GetTako/tako/blob/main/container.go#L32>)

```go
func Bind[T any](c contracts.Container, impl T)
```

Bind registers a singleton of type T. The implementation must satisfy T. This is the generic equivalent of app.Container\(\).Singleton\(\(\*T\)\(nil\), impl\).

```
tako.Bind[contracts.Logger](app.Container(), &myLogger{})
```

<a name="BindLazy"></a>
## func [BindLazy](<https://github.com/GetTako/tako/blob/main/container.go#L43>)

```go
func BindLazy[T any](c contracts.Container, factory func() (any, error))
```

BindLazy registers a lazy factory of type T that is resolved and cached on the first Make call.

```
tako.BindLazy[contracts.Database](app.Container(), func() (any, error) {
    return sql.Open("sqlite3", dsn)
})
```

<a name="BindTransient"></a>
## func [BindTransient](<https://github.com/GetTako/tako/blob/main/container.go#L54>)

```go
func BindTransient[T any](c contracts.Container, factory func() (any, error))
```

BindTransient registers a transient factory of type T. A new instance is created on every Make call.

```
tako.BindTransient[contracts.Validator](app.Container(), func() (any, error) {
    return &OrderValidator{errors: make([]string, 0)}, nil
})
```

<a name="MustResolve"></a>
## func [MustResolve](<https://github.com/GetTako/tako/blob/main/container.go#L20>)

```go
func MustResolve[T any](c contracts.Container) T
```

MustResolve resolves a service of type T from the given container. Panics if the service is not registered. Use only for bindings that are architecturally guaranteed to exist at call time \(e.g., boot\-time code\).

```
bus := tako.MustResolve[contracts.EventBus](app.Container())
```

<a name="Resolve"></a>
## func [Resolve](<https://github.com/GetTako/tako/blob/main/container.go#L9>)

```go
func Resolve[T any](c contracts.Container) (T, error)
```

Resolve resolves a service of type T from the given container. Returns the zero value of T and an error if not found.

```
db, err := tako.Resolve[contracts.Database](app.Container())
```
