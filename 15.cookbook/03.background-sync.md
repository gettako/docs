This recipe polls a remote API every 30 seconds and pushes the results into state so your UI updates automatically. You'll use the Scheduler, State Manager, and Events.

## The Provider

```go [providers/sync/provider.go]
package sync

import (
    "context"
    "encoding/json"
    "net/http"
    "time"

    "gettako.dev/tako/pkg/foundation"
)

type Order struct {
    ID     string  `json:"id"`
    Total  float64 `json:"total"`
    Status string  `json:"status"`
}

type Provider struct {
    stopPolling func()
}

func (p *Provider) Boot(app *foundation.Application) error {
    ctx := app.Context()
    // 1. Initial fetch
    job := ctx.Jobs().Dispatch(func(c context.Context) (any, error) {
        return fetchOrders(c)
    })
    job.OnSuccess(func(data any) {
        ctx.State().Set("orders", data)
        ctx.State().Set("orders.loading", false)
    })
    job.OnError(func(err error) {
        ctx.Logger().Error("initial fetch failed", "err", err)
        ctx.State().Set("orders.loading", false)
        ctx.State().Set("orders.error", err.Error())
    })

    ctx.State().Set("orders.loading", true)

    // 2. Poll every 30 seconds
    p.stopPolling = ctx.Jobs().Every(30*time.Second, func() {
        pollJob := ctx.Jobs().Dispatch(func(c context.Context) (any, error) {
            return fetchOrders(c)
        })
        pollJob.OnSuccess(func(data any) {
            ctx.State().Set("orders", data)
            ctx.Emit("orders:refreshed", data)
        })
    })

    // 3. Cleanup happens in Shutdown
    return nil
}

func (p *Provider) Shutdown() error {
    if p.stopPolling != nil {
        p.stopPolling()
    }
    return nil
}

func fetchOrders(ctx context.Context) ([]Order, error) {
    req, _ := http.NewRequestWithContext(ctx, "GET", "https://api.example.com/orders", nil)
    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Unmount()

    var orders []Order
    json.NewDecoder(resp.Body).Decode(&orders)
    return orders, nil
}
```

## Reacting in the UI

Any other provider (or your layout) can observe the orders state:

```go [providers/dashboard/provider.go]
func (p *DashboardProvider) Boot(app *foundation.Application) error {
    ctx := app.Context()
    watcher := ctx.State().Watch("orders")
    watcher.Debounce(200 * time.Millisecond)
    watcher.OnUpdate(func(old, new any) {
        // Your layout reads from state, so updating this local reference
        // will trigger a re-render showing the new data
        p.orders = new.([]Order)
    })
    watcher.Subscribe(ctx.Context())
    return nil
}
```

## Key Takeaways

- **Headless providers**: This provider has no UI; it just does background work. It activates automatically on boot.
- **`Dispatch` for one-offs**: The initial fetch returns immediately; callbacks fire when done.
- **`Every` for polling**: Returns a stop function that you should tie to the lifecycle via `OnDeactivate`.
- **State drives UI**: Push data into state, and let observers react. You don't need manual re-render calls.
- **Context propagation**: `Dispatch` receives a context that cancels automatically on shutdown, preventing leaked goroutines.
