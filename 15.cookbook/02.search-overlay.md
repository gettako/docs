This recipe builds a search component that can be dropped into any Tako app. You'll use: **Components**, **Overlays**, **Events**, **Hooks**.

## The Component

```go [components/search.go]
package components

import (
    "strings"

    "gettako.dev/tako/contracts"
)

type SearchBox struct {
    query   string
    results []string
    cursor  int
    source  []string
    onSelect func(item string)
}

func NewSearchBox(source []string, onSelect func(string)) *SearchBox {
    return &SearchBox{
        source:   source,
        results:  source,
        onSelect: onSelect,
    }
}

func (s *SearchBox) ID() string { return "search" }

func (s *SearchBox) Render() any {
    var b strings.Builder
    b.WriteString("🔍 " + s.query + "█\n")
    b.WriteString(strings.Repeat("─", 30) + "\n")

    for i, item := range s.results {
        prefix := "  "
        if i == s.cursor {
            prefix = "> "
        }
        b.WriteString(prefix + item + "\n")
    }
    return b.String()
}

func (s *SearchBox) RegisterKeys(keys contracts.KeyManager) {
    keys.Zone(s.ID()).Bind("esc", func() {}) // Overlay will be closed by the provider that showed us
    keys.Zone(s.ID()).Bind("enter", func() {
        if s.cursor < len(s.results) && s.onSelect != nil {
            s.onSelect(s.results[s.cursor])
        }
    })
    keys.Zone(s.ID()).Bind("j", func() {
        if s.cursor < len(s.results)-1 {
            s.cursor++
        }
    })
    keys.Zone(s.ID()).Bind("k", func() {
        if s.cursor > 0 {
            s.cursor--
        }
    })
}

func (s *SearchBox) filter() {
    if s.query == "" {
        s.results = s.source
        return
    }
    s.results = nil
    q := strings.ToLower(s.query)
    for _, item := range s.source {
        if strings.Contains(strings.ToLower(item), q) {
            s.results = append(s.results, item)
        }
    }
    s.cursor = 0
}
```

## Showing It

From any provider, trigger the search overlay with `ctrl+f`:

```go [providers/nav/provider.go]
func (p *Provider) Boot(app *foundation.Application) error {
    ctx := app.Context()
    ctx.Keys().Bind("ctrl+f", func() {
        items := []string{"Dashboard", "Orders", "Customers", "Settings", "Reports"}

        search := components.NewSearchBox(items, func(selected string) {
            ctx.UI().Unmount()
            ctx.Emit("navigate", selected)
        })

        ctx.UI().MountOverlay(search)
    })

    ctx.Keys().Bind("esc", func() {
        if ctx.UI().IsActive() {
            ctx.UI().Unmount()
        }
    })

    return nil
}
```

## Key Takeaways

- **Component = UI + Keys bundled** — `SearchBox` carries its own render logic and keybindings. No wiring needed outside.
- **MountOverlay does everything** — pushes stack, registers hooks, binds keys, shifts focus. One call.
- **Reusable** — pass different `source` slices and `onSelect` callbacks. Same component, different data.
- **Escape closes** — register a global `esc` that checks `IsActive()` for clean dismissal.
