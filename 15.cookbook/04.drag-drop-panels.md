This recipe builds a two-panel layout where items can be dragged from one panel to the other. You'll use the Mouse Router, State Manager, and Key Router.

## Registering Panels

```go [providers/filemgr/provider.go]
package filemgr

import (
	"gettako.dev/tako/internal/tako"
	"gettako.dev/tako/pkg/foundation"
)

type Provider struct {
	leftItems  []string
	rightItems []string
	focused    string // "left" or "right"
}

func (p *Provider) Boot(app *foundation.Application) error {
	ctx := app.Context()
	p.leftItems = []string{"README.md", "main.go", "go.mod"}
	p.rightItems = []string{"config.yaml", "Makefile"}
	p.focused = "left"

	// 1. Keyboard: switch panels with tab
	ctx.Keys().Bind("tab", func() {
		if p.focused == "left" {
			p.focused = "right"
		} else {
			p.focused = "left"
		}
		ctx.State().Set("filemgr.focused", p.focused)
	})

	// 2. Mouse: drag and drop between panels
	ctx.Mouse().Zone("left-panel").OnDrop(func(fromZone string, x, y int) {
		if fromZone == "right-panel" {
			// Move item from right to left
			if len(p.rightItems) > 0 {
				item := p.rightItems[0] // Simplified — in reality, use 'y' to pick the item
				p.rightItems = p.rightItems[1:]
				p.leftItems = append(p.leftItems, item)
				p.syncState(ctx)
			}
		}
	})

	ctx.Mouse().Zone("right-panel").OnDrop(func(fromZone string, x, y int) {
		if fromZone == "left-panel" {
			if len(p.leftItems) > 0 {
				item := p.leftItems[0]
				p.leftItems = p.leftItems[1:]
				p.rightItems = append(p.rightItems, item)
				p.syncState(ctx)
			}
		}
	})

	// 3. Click to select
	ctx.Mouse().Zone("left-panel").OnClick(func(x, y int) {
		p.focused = "left"
		ctx.State().Set("filemgr.focused", "left")
	})

	ctx.Mouse().Zone("right-panel").OnClick(func(x, y int) {
		p.focused = "right"
		ctx.State().Set("filemgr.focused", "right")
	})

	p.syncState(ctx)
	return nil
}

func (p *Provider) syncState(ctx *tako.Context) {
	ctx.State().Set("filemgr.left", p.leftItems)
	ctx.State().Set("filemgr.right", p.rightItems)
}
```

## Layout Hitbox Registration

In your layout's `Render` method, declare hitboxes each cycle:

```go [layouts/base.go]
func (l *Base) Render(ctx *takoCtx.Context, r *router.Router) tea.View {
    // Declare where each panel is on screen
    ctx.Mouse().UpdateHitbox("left-panel", 0, 1, 40, 20)
    ctx.Mouse().UpdateHitbox("right-panel", 42, 1, 40, 20)

    // Render panels using state...
    return tea.NewView(output)
}
```

## Key Takeaways

- **`UpdateHitbox` every render**: Terminal sizes and panel positions can change with window resizing, so always redeclare hitboxes during layout renders.
- **`OnDrop` receives `fromZone`**: You know exactly where the drag started, which simplifies cross-panel move logic.
- **Click and keyboard synergy**: Mouse clicks set focus, and the tab key switches it. Both update the same underlying state.
- **State drives rendering**: Mutate the backing slices, push them to state, and let the layout read and render the changes.
