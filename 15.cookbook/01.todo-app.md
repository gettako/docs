This recipe builds a todo list with keyboard navigation, add/delete via overlay, and persistent storage. You'll use: **State Manager**, **Key Router**, **Overlays**, **KV Storage
**.

## What You'll Build

- List of todos with cursor navigation (`j`/`k`)
- Add new todo via overlay prompt (`a`)
- Toggle complete (`enter`)
- Delete with confirmation dialog (`d`)
- Persists across restarts

## The Provider

```go [providers/todo/provider.go]
package todo

import (
	"gettako.dev/tako/contracts"
	"gettako.dev/tako/internal/tako"
	"gettako.dev/tako/pkg/foundation"
)

type Item struct {
	Text string `json:"text"`
	Done bool   `json:"done"`
}

type Provider struct {
	items  []Item
	cursor int
}

func (p *Provider) Boot(app *foundation.Application) error {
	ctx := app.Context()

	// Load saved todos
	ctx.Storage().Get("todos", &p.items)

	// Emit state
	ctx.State().Set("todo.items", p.items)
	ctx.State().Set("todo.cursor", p.cursor)

	// Register keys
	ctx.Keys().Zone("todo").Bind("j", func() { p.move(ctx, 1) })
	ctx.Keys().Zone("todo").Bind("k", func() { p.move(ctx, -1) })
	ctx.Keys().Zone("todo").Bind("enter", func() { p.toggle(ctx) })
	ctx.Keys().Zone("todo").Bind("a", func() { p.showAddOverlay(ctx) })
	ctx.Keys().Zone("todo").Bind("d", func() { p.confirmDelete(ctx) })

	// Provide the hook for rendering
	ctx.Hooks().Set("render:main", func() any {
		return p.renderList()
	})

	return nil
}

func (p *Provider) move(ctx *tako.Context, delta int) {
	p.cursor += delta
	if p.cursor < 0 {
		p.cursor = 0
	}
	if p.cursor >= len(p.items) {
		p.cursor = len(p.items) - 1
	}
	ctx.State().Set("todo.cursor", p.cursor)
}

func (p *Provider) toggle(ctx *tako.Context) {
	if len(p.items) == 0 {
		return
	}
	p.items[p.cursor].Done = !p.items[p.cursor].Done
	p.save(ctx)
}

func (p *Provider) confirmDelete(ctx *tako.Context) {
	if len(p.items) == 0 {
		return
	}
	item := p.items[p.cursor]
	ctx.UI().Dialog().Confirm("Delete \""+item.Text+"\"?", func(yes bool) {
		if yes {
			p.items = append(p.items[:p.cursor], p.items[p.cursor+1:]...)
			if p.cursor >= len(p.items) && p.cursor > 0 {
				p.cursor--
			}
			p.save(ctx)
		}
	})
}

func (p *Provider) showAddOverlay(ctx *tako.Context) {
	ctx.UI().Show("todo-add", func() any {
		return "New todo: (type and press enter)"
	})
	// In real app you'd wire an Input component here
}

func (p *Provider) save(ctx *tako.Context) {
	ctx.State().Set("todo.items", p.items)
	ctx.State().Set("todo.cursor", p.cursor)
	ctx.Storage().Set("todos", p.items)
}

func (p *Provider) renderList() any {
	// Your rendering logic here — build a string with cursor indicator
	return "todo list view"
}
```

## Key Takeaways

- **State as source of truth** — the list and cursor position live in state, the layout reads state to render
- **Overlay for modals** — adding and confirming delete use the overlay system, focus automatically traps
- **KV for persistence** — `Storage().Set/Get` saves across restarts with zero config
- **Zone-scoped keys** — all keys are bound to `"todo"` zone, won't conflict with other panels
