## Frequently Asked Questions

### Is Tako a replacement for Bubble Tea?
**No.** Tako is a UI-agnostic framework that provides architecture (Dependency Injection, Event Bus, Plugin System) around your chosen UI library. The core framework has **zero UI library dependencies**. If you want to use Bubble Tea, install the optional adapter submodule:
```bash
go get github.com/gettako/tako/pkg/adapter/bubbletea
```
You can also use `tview`, `tcell`, or any other library by implementing the `contracts.UIRenderer` interface.

### Can I use Tako without the Plugin System?
**Yes.** You can use Tako purely for its Service Container, Event Bus, and Key Router without ever creating a plugin. Just register your layout in `main.go` and start the app.

### Does Tako work on Windows?
**Yes.** Tako is purely written in Go and inherits the cross-platform capabilities of your chosen UI renderer. The core framework and all built-in dev tools work on any terminal that supports ANSI escape codes (Windows Terminal, macOS Terminal, Linux terminals).

## Common Issues

### 1. My keybindings aren't firing!

**Check the Stack Level and Focus:**
Keybindings in Tako are scoped to specific "Zones" and "Stack Levels". 
- If you bound a key to the `"search"` zone, but your layout currently has `"file-list"` focused, the key will not fire.
- Ensure you have called `app.Router().Focus(0, "search")` to shift the input router's attention to your zone.

### 2. My UI isn't updating after an event fires!

**Check your Hooks:**
When you change state in a plugin, the UI won't reflect it unless you trigger a render. If you're using the Bubble Tea adapter (from `github.com/gettako/tako/pkg/adapter/bubbletea`), renders happen automatically on `tea.Msg` — the adapter listens to the Event Bus and triggers a UI re-render on the next frame when you call `ctx.Emit("state:changed", nil)`. For custom adapters, ensure your event loop callback triggers a redraw. See [UI Adapters](../ui/adapters.md) for details.

### 3. The Inspector shows 0 FPS!

**Check your Profiler calls:**
If you are writing a custom UI adapter (not Bubble Tea), you must manually call `RecordView()` and `RecordUpdate()` in your render loop. See the [Profiler Integration](../ui/profiler-integration.md) guide.

### 4. "Dependency not found" panic during boot

If you request a service via `ctx.Container().Make(&myService)` and it panics, it means no plugin or bootstrap code registered that interface.
Check your `Plugin.Dependencies()` method to ensure you explicitly declare that your plugin requires the service provider to boot first.
