In vanilla Bubble Tea, handling user input often results in large, unreadable `switch` statements inside your `Update` method. Tako eliminates this completely by providing a dedicated **Input Manager**.

The Input Manager allows you to bind specific keys to closure functions. You can bind keys globally (so they work anywhere in the app) or scope them specifically to a single View.

## Global Keybindings

Global keybindings are active no matter which screen the user is currently on. The most common use case for a global keybinding is exiting the application (e.g., `Ctrl+C` or `q`).

You typically register global keybindings inside your `main.go` file before running the application, or inside a Service Provider's `Boot` method.

```go
func main() {
	app := tako.NewApp()

	// Bind Ctrl+C globally to quit the app
	app.Input().Global().Bind("ctrl+c", func(ctx contracts.InputContext) {
		if ui, err := contracts.Resolve[contracts.UIManager](app, "ui.manager"); err == nil {
			ui.Quit()
		}
	})

	tako.Run(app)
}
```

The `Bind` method takes two arguments:
1. **The key string**: This follows standard Bubble Tea key names (e.g., `"enter"`, `"esc"`, `"up"`, `"a"`, `"ctrl+c"`).
2. **The handler function**: A closure that receives a `contracts.InputContext`.

## Scoped Keybindings (Component Level)

Most of the time, you only want a keyboard shortcut to work when a specific screen is visible. For example, pressing `s` to save should only work if the user is on the Settings screen.

To do this, your View must implement the `contracts.KeyBinder` interface by adding a `Keys()` method. 

```go
package components

import "gettako.dev/tako/contracts"

type SettingsScreen struct {}

func (s *SettingsScreen) Render(ctx contracts.Context) string {
	return "Press 's' to save settings, or 'esc' to go back."
}

// Implementing contracts.KeyBinder
func (s *SettingsScreen) Keys(km contracts.InputManager) {
	
	km.Bind("s", func(ctx contracts.InputContext) {
		// Save logic here...
	})

	km.Bind("esc", func(ctx contracts.InputContext) {
		// Navigate back
		ctx.Router().Back()
	})
	
}
```

**How it works:** When the Router navigates to `SettingsScreen`, Tako automatically calls its `Keys` method and registers `"s"` and `"esc"`. The moment the user navigates away from the screen, Tako automatically unregisters these keys. You never have to manually clean up keybindings!

## The Input Context

Every keybinding handler receives a `contracts.InputContext`. This context is incredibly powerful because it provides immediate access to the application instance and the TUI Router.

```go
km.Bind("enter", func(ctx contracts.InputContext) {
	// Access the router to navigate
	ctx.Router().Navigate("dashboard")

	// Check if we need to stop propagation
	if ctx.Key() == "enter" {
		ctx.StopPropagation()
	}
})
```

## Advanced Input (Raw Messages)

If you need to handle raw typing (for example, typing a username into a text field), simple keybindings won't work because you need to capture every single character.

For these cases, refer to the [Views documentation](/the-basics/views#handling-raw-messages-optional) on how to implement the `contracts.MessageHandler` interface to process raw Bubble Tea `tea.KeyMsg` structs.
