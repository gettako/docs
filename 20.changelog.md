## [0.1.0] — 2026-06-14

### Added

- **Service Container** — IoC with Singleton, Lazy, Transient bindings, closure injection, type-safe generic helpers, and robust factory panic recovery
- **Plugin System** — DAG-based dependency resolution, lifecycle hooks (`OnActivate`/`OnDeactivate`), inline plugins
- **Event Bus** — Pub/sub with context-aware auto-cleanup, wildcard subscriptions, typed events, and $O(1)$ fixed-size ring buffer history
- **RPC Bus** — Synchronous inter-plugin request/response with timeouts, guards, and retries
- **Key Router** — Focus stack with zone-scoped keybindings, auto-focus, key normalization, and thread-safe TOCTOU-free layer popping
- **Mouse Router** — Hitbox-based click/scroll/drag-drop routing with stack-level isolation
- **State Manager** — Reactive state with TTL, LRU eviction, fluent APIs, deadlock-safe event publishing, and robust shutdown signal handling
- **Overlay System** — Managed overlay stack with component wiring, focus trapping, dialogs
- **Hook System** — Single-slot and multi-slot named render providers
- **Scheduler** — Background job dispatch with callbacks, periodic tickers, and a native 5-field cron syntax scheduler
- **Cache** — TTL-based file cache with cache-aside pattern, $O(1)$ file-per-key sharding, singleflight stampede prevention, and background garbage collection
- **CLI System** — Commands with middleware, builder, and signature parsing
- **Configuration** — YAML/JSON file loading with dot-notation access and env overrides
- **Logger** — Structured file-based logging with subsystem tracing via `With(key, val)` context binding
- **KV Storage** — Persistent JSON-backed key-value store
- **Theming & i18n** — Runtime switching with semantic color tokens, locale definitions, auto-loading language files, and named parameter replacements
- **Adapters** — Bubble Tea integration, abstract base adapter, tcell support
- **Time Travel** — Event recorder with field masking, compression, and interactive replay player
- **DevTools** — Live WebSocket debugger with profiler metrics, stack visualization, plugin status
- **Hot Reload** — File watcher with debouncing for `tako dev` command
- **Documentation** — Comprehensive guides including separated Troubleshooting and FAQ, with modern alerts

### Notes

This is the initial release. The API surface is stable for the documented public contracts but internal packages may change between minor versions.

## Versioning Policy

Tako follows semantic versioning:

- **Patch** (0.1.x) — Bug fixes, no API changes
- **Minor** (0.x.0) — New features, backward-compatible
- **Major** (x.0.0) — Breaking changes to public contracts

::note
During the `0.x` series, minor versions may contain breaking changes to internal packages. Public contracts (`contracts/*`) and the `tako` package top-level API remain stable
within a minor version.
::
