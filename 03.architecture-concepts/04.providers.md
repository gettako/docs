Service Providers are the central place where all Tako applications are bootstrapped. Your application, as well as all of Tako's core services, are bootstrapped via service providers.

But what do we mean by "bootstrapped"? In general, we mean **registering** things, including binding services into the container, registering event listeners, attaching middleware, or booting database connections.

## The Provider Interface

Every service provider in Tako must implement the `contracts.ServiceProvider` interface. This interface forces you to implement two methods: `Register` and `Boot`.

```go [providers/example_provider.go]
package providers

import "gettako.dev/tako/contracts"

type ExampleProvider struct{}

func (p *ExampleProvider) Register(app contracts.Application) {
	// Bind things into the container here
}

func (p *ExampleProvider) Boot(app contracts.Application) {
	// Execute logic after all providers are registered here
}
```

### The `Register` Method

Within the `Register` method, you should **only bind things into the Service Container**. You should never attempt to register any event listeners, routes, or try to use any other service within this method. 

Why? Because if you try to use a service (like a logger or a database) inside the `Register` method, there is a very high chance that the provider responsible for creating that service hasn't run its `Register` method yet!

```go
func (p *ExampleProvider) Register(app contracts.Application) {
	app.Singleton("example.service", func(c contracts.Container) any {
		return NewExampleService()
	})
}
```

### The `Boot` Method

This method is called after all other Service Providers have been registered. This means you have access to every other service that has been bound to the container!

If you need to listen to global events, resolve the logger, or initialize a TUI component, the `Boot` method is exactly where you do it.

```go
func (p *ExampleProvider) Boot(app contracts.Application) {
	// It is now safe to resolve services!
	if logger, err := contracts.Resolve[contracts.Logger](app, "logger"); err == nil {
		logger.Info("ExampleProvider has finished booting!")
	}
}
```

## Registering Providers

To make Tako aware of your service provider, you simply register it into your application instance before calling `tako.Run(app)`.

Usually, this is done inside your `main.go` file:

```go [main.go]
package main

import (
	"gettako.dev/tako"
	"my-tako-app/providers"
)

func main() {
	app := tako.NewApp()

	// Register your custom providers
	app.Register(&providers.ExampleProvider{})
	app.Register(&providers.DatabaseProvider{})

	tako.Run(app)
}
```

Tako will automatically queue them up, run all their `Register` methods first, and then sequentially run all their `Boot` methods.
