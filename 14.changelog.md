# Changelog

All notable changes to the Tako Framework will be documented in this file. Tako adheres strictly to [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- **Fluent Syntax**: Introduced chainable builders across the entire framework (e.g., `app.WithProviders()`, `app.Router().Scope()`).
- **Context Sugar**: Added `ctx.RenderNow()` as a syntactic sugar for `ctx.UI().RequestRender()`.
- **Event Dispatcher**: New fluent builder for emitting events `ctx.Events().Dispatch("name").WithPayload(data).Delay(time).Fire()`.
- **Dual-Dimension Path Handling**: Framework now automatically handles `.tako/` directory for Dev Mode, and `~/.app-name/` for Prod Mode to ensure safe storage.
- **RPC Bus**: Full implementation of Unix Domain Sockets IPC for background daemon communication.

### Changed
- **UI Architecture**: Decoupled the rendering engine entirely into the UI Adapter pattern (`contracts.UIManager`). Bubbletea is now injected rather than hardcoded.
- **Routing**: `Group()` has been optimized, and `Scope()` has been added to provide isolated router instances for cleaner middleware chaining.

### Deprecated
- `app.UI().Render()` manually is deprecated in favor of letting the UI Adapter handle the event loop.
- Accessing global variables is strictly prohibited and actively linted against.

### Fixed
- Fixed memory leaks in Event Bus listeners by implementing automatic context cancellation tracking.
- Resolved race conditions in the State Manager when broadcasting values rapidly across multiple goroutines.

## [1.0.0] - Initial Release

- Core Inversion of Control (IoC) Container.
- Service Providers lifecycle (Register & Boot).
- Basic Router with history stack.
- Input Manager with keyboard binding support.
- CLI Command registry.
