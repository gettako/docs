Welcome to Tako. Tako is a Terminal User Interface (TUI) framework for Go. If you have experience building web applications using frameworks like Laravel or Nuxt, you will feel familiar with our approach.

We built Tako focusing on developer experience. Building terminal applications should not require you to manage global variables or complex rendering loops manually. Tako provides a structured foundation so you can focus on building features instead of boilerplate.

## Why Tako?

Building CLI or TUI applications can lead to scattered state management, complex navigation logic, and codebases that are difficult to test. Tako addresses this by providing:

- **Dependency Injection:** An inversion of control (IoC) container handles creating and injecting your services automatically. This removes the need for global variables like `var DB *Database`.
- **Service Providers:** Dedicated structures to set up third-party libraries, databases, and background tasks before your UI starts.
- **Routing:** Navigate between terminal screens similar to web applications, supporting dynamic path matching and middlewares.
- **Event Bus:** A predictable way for your components to communicate without being tightly coupled.
- **Familiar Abstractions:** Extensible managers for Caching, Storage, State, and UI rendering.

## Core Principles

Tako adheres to a few core principles to keep your codebase clean and predictable:

1. **No Global State:** Everything belongs to an instance and is resolved through the application's Container or Context.
2. **Design by Contract:** Components depend on interfaces located in the `contracts/` directory. This allows you to swap out underlying implementations without breaking your application.
3. **Graceful Fallbacks:** Tako is designed to avoid panics by providing sensible defaults when configuration keys or dependencies are missing.
