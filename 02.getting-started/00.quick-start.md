## Scaffold a New Project

```bash [terminal]
mkdir myapp && cd myapp
go mod init myapp
go get gettako.dev/tako
go get gettako.dev/tako/pkg/adapter/ui/bubbletea
```

## Create `main.go`

```go [main.go]
package main

import (
    "log"

    "gettako.dev/tako"
    "gettako.dev/tako/contracts"
    "gettako.dev/tako/pkg/adapter/ui/bubbletea"
    "gettako.dev/tako/pkg/foundation"
)

// Layout is your root view. Implement contracts.Component.
type Layout struct{}

func (l *Layout) ID() string {
    return "dashboard"
}

func (l *Layout) Render() any {
    return "Dashboard ready. Press ctrl+c to exit.\n"
}

func (l *Layout) RegisterKeys(keys contracts.KeyManager) {}

func main() {
    app := tako.NewApp()

    // Set Root Layout (App.vue equivalent)
    app.UI().Layout(&Layout{})

    // Mount to Terminal
    app.Mount(bubbletea.NewAdapter(app.Context(), nil))

    if err := tako.Run(app); err != nil {
        log.Fatal(err)
    }
}
```

## Run

```bash [terminal]
go run -race .
```

You should see your message in alt-screen mode. Press `ctrl+c` to exit.

## Try the CLI

Every Tako app also works as a CLI tool — no extra setup required:

```bash [terminal]
go run . help
go run . version
go run . status
```

## Add a Keybinding

```go [main.go]
func main() {
    app := tako.NewApp()

    // Fires from any focus state — a true global shortcut
    app.Keys().Bind("ctrl+r", func() { app.Logger().Info("manual refresh triggered") })

    // You can optionally chain Bind() calls, but listing them separately is often cleaner
    app.Keys().Bind("ctrl+q", func() { app.Shutdown() })
    app.Keys().Bind([]string{"?", "f1"}, showHelp)

    app.UI().Layout(&Layout{})
    app.Mount(bubbletea.NewAdapter(app.Context(), nil))
    tako.Run(app)
}
```

## Add a Provider

Create `providers/orders/provider.go`:

```go [providers/orders/provider.go]
package orders

import (
    "gettako.dev/tako/contracts"
    "gettako.dev/tako/pkg/foundation"
)

type OrderProvider struct {
    activeCount int
}

func (p *OrderProvider) Register(app *foundation.Application) error {
    return nil
}

func (p *OrderProvider) Boot(app *foundation.Application) error {
    app.Events().Subscribe(app.Context(), "order:created", func(e contracts.Event) {
        p.activeCount++
    })
    return nil
}
```

Register it in `main.go`:

```go [main.go]
app.RegisterProviders(&orders.OrderProvider{})
```

::tip
Keep all `RegisterProviders` calls in `main.go`. This makes your application's feature set visible at a glance without hunting through subdirectories.
::
