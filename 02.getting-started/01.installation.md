Setting up a new terminal application from scratch can be repetitive. Tako is designed to simplify the initial setup process.

## Prerequisites

Tako utilizes modern Go features. You need two things before you begin:
- **Go 1.22** or higher installed on your machine.
- A basic understanding of Go modules and interfaces.

## Initializing a New Project

To start our case study, Server Dash, let's create a Go module. Open your terminal and run:

```bash
mkdir server-dash
cd server-dash
go mod init github.com/yourusername/server-dash
```

## Installing Tako

Add Tako to your project using `go get`. This command downloads the core framework, its interfaces, and necessary dependencies.

```bash
go get gettako.dev/tako
```

::tip
We recommend using the latest version of Tako to take advantage of the newest features and improvements.
::

## Verifying the Installation

Let's make sure the installation was successful. Create a `main.go` file and import the Tako core:

```go [main.go]
package main

import (
    "fmt"
    
    "gettako.dev/tako"
)

func main() {
    app := tako.NewApp()
    
    fmt.Printf("Initialized %s\n", app.Name())
}
```

Run the file from your terminal:
```bash
go run main.go
```

If the installation was successful, you will see the framework's name printed in the terminal.

::note
This is a standard application initialization without a user interface. In the next chapter, we will mount a UI adapter and boot up a terminal interface.
::
