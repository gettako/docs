Welcome to Tako! This guide will help you get your first Tako application up and running in just a few minutes.

## Prerequisites

Before installing Tako, make sure your development environment meets the following requirements:

* **Go 1.21 or higher** installed on your machine.
* A basic understanding of Go modules.

## Creating a New Project

First, create a new directory for your project and initialize a Go module:

```bash
mkdir my-tako-app
cd my-tako-app
go mod init my-tako-app
```

## Installing the Framework

Install Tako by running the standard `go get` command. This will fetch the latest version of the framework and its dependencies (like Bubble Tea and Lip Gloss):

```bash
go get gettako.dev/tako
```

## Your First Application

Let's build a very simple application to verify everything is working. Create a `main.go` file in the root of your project:

```go [main.go]
package main

import (
	"fmt"
	"os"

	"gettako.dev/tako"
	"gettako.dev/tako/contracts"
)

// HelloScreen is a simple TUI view
type HelloScreen struct {}

func (h *HelloScreen) Init() contracts.Cmd {
	return nil
}

func (h *HelloScreen) Update(msg contracts.Msg) (contracts.View, contracts.Cmd) {
	return h, nil
}

func (h *HelloScreen) View() string {
	return "Hello, Tako! Press 'q' to quit."
}

func main() {
	// 1. Initialize the application
	app := tako.NewApp()

	// 2. Configure the TUI Router
	router := app.TUI().Router()
	router.Route("/", func() contracts.View {
		return &HelloScreen{}
	}).Name("home")

	// 3. Navigate to the initial route
	if err := router.Navigate("home"); err != nil {
		fmt.Println("Error navigating to home:", err)
		os.Exit(1)
	}

	// 4. Bind global exit keys
	app.Input().Global().Bind("q", func(_ contracts.InputContext) {
		if ui, err := contracts.Resolve[contracts.UIManager](app, "ui.manager"); err == nil {
			ui.Quit()
		}
	})

	// 5. Run the application
	tako.Run(app)
}
```

## Running Your Application

Now, simply run your application:

```bash
go run main.go
```

You should see your terminal clear and display "Hello, Tako! Press 'q' to quit." 

Congratulations! You have successfully installed and run your first Tako application.

::tip
Tako intelligently handles application booting. It will automatically detect if you passed command-line arguments to run a CLI Command. If no commands are passed, it defaults to launching the TUI Engine.
::
