Welcome to Tako! This guide will help you install the framework and prepare your environment for building terminal applications.

## Prerequisites

Before installing Tako, make sure your development environment meets the following requirements:

* **Go 1.21 or higher** installed on your machine.
* A basic understanding of Go modules.

## Creating a New Project

First, create a new directory for your project and initialize a Go module. You can name your module whatever you like.

```bash
mkdir my-tako-app
cd my-tako-app
go mod init my-tako-app
```

## Installing the Framework

Install Tako by running the standard `go get` command. This will fetch the latest version of the framework and its core dependencies, including Bubble Tea and Lip Gloss.

```bash
go get gettako.dev/tako
```

That's it! Your environment is now ready.

::tip
You can verify the installation by checking your `go.mod` file. You should see `gettako.dev/tako` listed under your dependencies.
::

## Next Steps
