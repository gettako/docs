Now that you have Tako installed, let's build a very simple application to verify everything is working and to get a feel for how the framework operates.

We will create a simple "Hello World" screen and route to it.

## The Entry Point

Create a `main.go` file in the root of your project. This file will serve as the entry point for your application.

```go [main.go]
package main

import (
	"fmt"
	"os"

	"gettako.dev/tako"
	"gettako.dev/tako/contracts"
)

// HelloScreen is a simple TUI view. It implements the contracts.View interface.
type HelloScreen struct {}

func (h *HelloScreen) Render(ctx contracts.Context) string {
	return "Hello, Tako! Press 'q' to quit."
}

func main() {
	// 1. Initialize the application and Service Container
	app := tako.NewApp()

	// 2. Configure the TUI Router
	router := app.TUI().Router()
	
	// Register our HelloScreen to the root path
	router.Route("/", func() contracts.View {
		return &HelloScreen{}
	}).Name("home")

	// 3. Navigate to the initial route
	if err := router.Navigate("home"); err != nil {
		fmt.Println("Error navigating to home:", err)
		os.Exit(1)
	}

	// 4. Bind a global key to exit the application
	app.Input().Global().Bind("q", func(_ contracts.InputContext) {
		if ui, err := contracts.Resolve[contracts.UIManager](app, "ui.manager"); err == nil {
			ui.Quit()
		}
	})

	// 5. Run the application
	tako.Run(app)
}
```

### Breaking it down

Let's look at what is happening in this code:
1. **The Screen:** We created a `HelloScreen` struct that implements the `contracts.View` interface. If you are familiar with Bubble Tea, this is exactly the same as the `Model` interface.
2. **The App:** We instantiate the framework using `tako.NewApp()`. This sets up the Service Container and core systems.
3. **Routing:** We grab the TUI Router from the app and register our screen under the name `home`. Then, we instruct the router to navigate there immediately.
4. **Global Input:** Instead of checking for the "q" key inside the screen's `Update` method, we bind it globally using the Input Manager. This means pressing "q" will quit the app no matter what screen you are on!
5. **Running:** `tako.Run(app)` takes over, boots the application, and launches the TUI.

## Running Your Application

Save the file and run your application from the terminal:

```bash
go run main.go
```

You should see your terminal clear and display "Hello, Tako! Press 'q' to quit." 

Congratulations! You have successfully built and run your first Tako application.

::tip
Tako intelligently handles application booting. It will automatically detect if you passed command-line arguments to run a CLI Command. If no commands are passed, it defaults to launching the TUI Engine.
::
