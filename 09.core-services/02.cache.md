In complex TUI applications, executing slow operations—such as querying a large SQLite database, parsing massive configuration files on disk, or making blocking HTTP requests—can freeze the UI thread and cause your application to lag. 

Tako provides a thread-safe `contracts.Cache` implementation to store these expensive computational results in memory temporarily.

## Accessing the Cache

You can access the cache instance using the Application or Context APIs:

```go
cache := ctx.Cache()
```

## Basic Operations

### Storing Data
Use `Set()` to store data. You provide a string key, the value to store, and a Time-To-Live (TTL). If the TTL is explicitly set to `0`, the item will live forever until manually purged.

```go
import "time"

// Cache a string for 5 minutes
err := ctx.Cache().Set("server-status", "ONLINE", 5 * time.Minute)
```

### Retrieving Data
Use `Get()` to pull data back out. You provide a pointer to the type you expect. The method returns `true` if the item was found and hasn't expired.

```go
var status string
if ctx.Cache().Get("server-status", &status) {
    ctx.Logger().Info("Status is: %s", status)
} else {
    ctx.Logger().Warning("Cache miss or key expired")
}
```

### Retrieving and Deleting (Pull)
If you need to retrieve an item and delete it in a single, atomic operation, use `Pull()`:

```go
var token string
if ctx.Cache().Pull("one-time-token", &token) {
    // The token is retrieved and removed from the cache
}
```

### Checking Existence
If you only need to know if a key currently exists (without paying the reflection cost of retrieving its value):

```go
if ctx.Cache().Has("server-status") {
    // The key is present.
}
```

## The Cache-Aside Pattern (`Remember`)

A common caching pattern in software engineering is:
1. Check if data exists in the cache.
2. If it does, return it.
3. If it doesn't, calculate the data, store it in the cache, and *then* return it.

Writing this boilerplate over and over is repetitive. Tako provides the `Remember()` method to accomplish this in a single method call.

```go
// Attempt to get the server list. If it doesn't exist, execute the closure,
// cache the result for 10 minutes, and return it.
servers, err := ctx.Cache().Remember("server-list", 10 * time.Minute, func() (any, error) {
    // This expensive closure ONLY runs if there is a cache miss
    return expensiveDatabaseQuery()
})

if err != nil {
    return err
}

// Cast the result back to your strong type
serverSlice := servers.([]Server)
```

By leveraging `Remember()`, you ensure your TUI remains responsive, as expensive database calls or HTTP requests are skipped entirely on subsequent renders.

### Caching Forever
If you want to remember a value indefinitely until it is manually cleared, you can use `Forever()`. This is functionally identical to `Remember()` but without needing to pass a TTL:

```go
config, err := ctx.Cache().Forever("app-config", func() (any, error) {
    return loadHeavyConfig()
})
```

## Clearing Cache

When data goes stale, purging the cache is simple:

```go
// Remove a single specific item
ctx.Cache().Forget("server-list")

// Clear everything (use with caution)
ctx.Cache().Clear()
```
