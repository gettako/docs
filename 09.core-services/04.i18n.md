Hardcoding English text directly into your terminal UI makes it difficult to adapt your application for a global audience.

Tako includes a built-in `contracts.LangManager` to handle dictionary translations, smart fallbacks, pluralizations, and dynamic runtime language switching.

## Accessing the Lang Manager

Like all core services, you can access the Lang Manager fluently from anywhere in the application:

```go
lang := ctx.Lang()
```

## Loading Dictionaries via YAML/JSON

Tako provides a filesystem loader to read translation files dynamically. You can organize your translations into folders based on locale codes (e.g. `en`, `id`).

```yaml
# lang/en/auth.yml
welcome: "Welcome back, :name!"
login_error: "Invalid credentials."
```

```yaml
# lang/id/auth.yml
welcome: "Selamat datang kembali, :name!"
login_error: "Kredensial tidak valid."
```

## Automatic Loading & Cascade

By default, Tako automatically loads translations from the `"lang"` directory. It follows a **strict fallback hierarchy**:

1. **Base Project** (`<project-root>/lang`): Your application's default translations.
2. **Dynamic Override** (`.tako/lang` or `~/.app-name/lang`): High-priority user translation overrides.

If a user creates a file with the same translation keys in the dynamic override folder, those keys will automatically replace the base project's translations.

You only need to configure the active locale:

```go
func (p *AppServiceProvider) Boot(app contracts.Application) error {
    // Tako automatically loads translations from the "lang" directory.
    
    // Set fallback language if a translation is missing
    app.Lang().SetFallback("en")
    
    // Set the default active language
    app.Lang().SetLocale("en")
    
    return nil
}
```

Tako uses **deep flattening** for YAML and JSON structures. For example, `auth.yml` automatically prefixes all keys inside it with `auth.`. Thus, the key becomes `"auth.welcome"`.

## Registering Translations Programmatically

If you prefer keeping your application compiled as a single binary without external files, you can register dictionaries programmatically.

```go
func (p *AppServiceProvider) Boot(app contracts.Application) error {
    
    // Register English Dictionary
    app.Lang().Register("en", map[string]string{
        "welcome": "Welcome back, :name!",
        "apples":  "{0} No apples|{1} One apple|[2,*] :count apples",
    })

    // Register Indonesian Dictionary
    app.Lang().Register("id", map[string]string{
        "welcome": "Selamat datang kembali, :name!",
        "apples":  "{0} Tidak ada apel|{1} Satu apel|[2,*] :count apel",
    })

    app.Lang().SetFallback("en")
    app.Lang().SetLocale("en")

    return nil
}
```

## Translating Text in Components

Tako provides a *syntactic sugar* wrapper directly on the `contracts.Context` to fetch translations. You no longer need to call `ctx.Lang().T()`.

```go
import "github.com/charmbracelet/lipgloss"

func (c *MyComponent) Render() string {
    // Basic translation
    title := c.ctx.T("auth.login_error")
    
    // Translation with parameter interpolation
    greeting := c.ctx.T("auth.welcome", "name", "Tako")
        
    return lipgloss.JoinVertical(lipgloss.Left, title, greeting)
}
```

## Pluralization (Choice)

Translating words based on counts (e.g. `1 apple` vs `2 apples`) is a difficult problem. Tako provides a Laravel-inspired `Choice` method to solve this.

First, define your pluralization template using the `|` separator:
```yaml
apples: "{0} No apples|{1} One apple|[2,*] :count apples"
```

Then, use `ctx.Choice()` and pass the count as the second argument:

```go
// Output: "No apples"
c.ctx.Choice("apples", 0)

// Output: "One apple"
c.ctx.Choice("apples", 1)

// Output: "5 apples"
c.ctx.Choice("apples", 5)
```

## Switching Languages Dynamically

You can allow users to change languages at runtime.

```go
func (c *SettingsComponent) Keys(km contracts.KeyManager) {
    km.Bind("I", func() {
        c.ctx.Lang().SetLocale("id")
        c.ctx.RenderNow()
    })
    
    km.Bind("E", func() {
        c.ctx.Lang().SetLocale("en")
        c.ctx.RenderNow()
    })
}
```

When `SetLocale()` is triggered, the Lang Manager automatically broadcasts a `lang:changed` event via the Event Bus, allowing other reactive services to respond to the user's new locale.

## Advanced API

The `LangManager` provides several other advanced methods:

- `Locales() []string`: Returns a sorted slice of all registered locales (e.g. `["en", "id"]`), which is useful for rendering Dropdown Language selection menus.
- `Has(key string) bool`: Checks if a translation key exists without returning the string.
- `Active() string`: Returns the currently active locale code.
- `Fallback() string`: Returns the fallback locale code.
