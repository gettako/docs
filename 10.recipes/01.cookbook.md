## Building a Standalone CLI Command

Tako applications can also function as headless CLI commands using the existing service container and plugins.

If you pass an argument to your application (e.g., `./app migrate`), the CLI Kernel takes over and executes it without launching the TUI.

```go [main.go]
package main

import (
    "flag"
    "github.com/gettako/tako"
    "github.com/gettako/tako/internal/cli"
)

type MigrateCommand struct {}

func (m *MigrateCommand) Name() string { return "migrate" }
func (m *MigrateCommand) Description() string { return "Run database migrations" }
func (m *MigrateCommand) Signature() string { return "" }

func (m *MigrateCommand) Execute(ctx *cli.Context, args []string) error {
    ctx.Info("Starting migrations...")
    
    // Your migration logic here...
    
    ctx.Success("Migrations complete!")
    return nil
}

func main() {
    app := tako.NewApp()
    
    // Register the command before running
    app.Commands(&MigrateCommand{})
    
    tako.Run(app)
}
```

## Global Command Palette (Ctrl+P)

You can implement a global command palette using the Overlay Manager.

```go [lifecycle.go]
func (p *MyPlugin) OnInit(ctx *tako.Context) error {
    // Register a global hotkey
    ctx.Keys().Bind("ctrl+p", func() {
        // Show the command palette component
        ctx.Overlay().ShowComponent(&CommandPalette{})
    })
    return nil
}
```

> [!NOTE]
> Global hotkeys are active across all layers unless explicitly overridden by the currently focused layer.

## Creating a Debounced Search

When typing in a search box, you don't want to hit your database on every single keystroke. Use a goroutine to debounce the input.

```go [lifecycle.go]
func (p *SearchPlugin) startDebouncer(ctx *tako.Context) {
    ctx.Spawn(func(c context.Context) {
        var timer *time.Timer
        
        // Listen for raw keystrokes
        ctx.On("search:type", func(e contracts.Event) {
            char := e.Data.(string)
            p.query += char
            
            if timer != nil {
                timer.Stop()
            }
            
            // Fire search after 300ms of inactivity
            timer = time.AfterFunc(300*time.Millisecond, func() {
                results := p.db.Search(p.query)
                ctx.Emit("search:results-ready", results)
            })
        })
    })
}
```

> [!WARNING]
> Always use `ctx.Spawn` instead of raw `go func()` to ensure your goroutines are properly cancelled when the application shuts down.

## Injecting an External Database

You can bind external dependencies into the Service Container before booting the application.

```go [main.go]
func main() {
    app := tako.NewApp()
    
    // Initialize your database
    db, _ := sql.Open("sqlite3", "./app.db")
    
    // Bind it into the container so plugins can ask for it
    app.Container().Singleton(new(*sql.DB), db)
    
    tako.Run(app)
}
```

In your plugin, simply resolve the dependency:

```go [lifecycle.go]
func (p *MyPlugin) OnInit(ctx *tako.Context) error {
    var db *sql.DB
    ctx.Container().Make(&db)
    
    // Use the database...
    return nil
}
```
