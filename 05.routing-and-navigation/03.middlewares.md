When building complex applications, you often need to protect certain screens. If a user isn't logged in, they shouldn't be able to view the Dashboard. 

Without middlewares, you are forced to inject authentication checks manually into the `Init()` method of every protected component. This creates code duplication and can lead to security holes if a developer forgets to add the check to a new route.

Tako brings web-style **Middlewares** to the terminal to solve this.

A Middleware in Tako is an interceptor function that runs *before* a navigation event (`GoTo`, `Back`, `Replace`) completes. It can inspect the destination route and decide whether to allow the navigation to proceed, or block it entirely.

## Writing a Middleware

A middleware function needs to match the `contracts.Middleware` signature:

```go
type Middleware func(ctx Context, to RouteInfo) bool
```

It takes the global Context and the destination `RouteInfo`. If it returns `true`, the navigation proceeds. If it returns `false`, the navigation is cancelled.

### Example: Auth Middleware
Let's create a middleware for our Server Dash that blocks access to the `/admin` routes if the user is not authenticated.

```go
func AuthMiddleware(ctx contracts.Context, to contracts.RouteInfo) bool {
    // Check our global State manager for an auth token
    isAuthenticated := ctx.State().Get("auth_token").Exists()

    if !isAuthenticated {
        // Log the security denial
        ctx.Logger().Warning("Unauthorized access attempt to " + to.Name)
        
        // Redirect the user to the login screen
        ctx.Router().Replace("login")
        
        // Return false to halt the original navigation to the admin route
        return false
    }

    // Allow navigation to proceed
    return true
}
```

## Applying Middlewares

Middlewares are flexible. They can be applied globally to the entire application, or scoped to specific route groups.

### 1. Global Application Middleware
If you want a middleware to intercept every route change across the entire application (for example, a `GlobalLogMiddleware` that records user navigation history), use the fluent builder on the application initialization:

```go
app := tako.NewApp().
    WithMiddleware(GlobalLogMiddleware)
```

### 2. Scoped Middleware
If you only want to protect a specific section within your app, apply the middleware to a Router Scope:

```go
app.Router().
    Scope("/admin").
    Use(AuthMiddleware).
    Root(adminLayout, func(admin contracts.Router) {
        admin.Route("/dashboard", components.NewAdminDash()).Name("admin.dash")
        admin.Route("/users", components.NewAdminUsers()).Name("admin.users")
    })
```
In this example, the `AuthMiddleware` will execute only when the user attempts to navigate to `admin.dash` or `admin.users`.

### 3. Route-Specific Middleware
For granular control, you can chain middlewares directly onto a single route builder:

```go
app.Router().
    Route("/destructive-action", components.NewNukeDatabase()).
    Name("danger.zone").
    Use(SuperAdminOnlyMiddleware)
```

## Middleware Execution Order

If multiple middlewares apply to a route, Tako executes them in the following order:
1. Global Application Middlewares
2. Scoped Middlewares (from the outermost scope cascading to the innermost scope)
3. Route-Specific Middlewares

If *any* middleware in the chain returns `false`, the chain breaks immediately and the navigation is halted.

::caution
Middlewares are executed synchronously during the navigation cycle. **Do not** perform heavy blocking I/O (like long network requests without timeouts) inside a middleware, as it will freeze the UI thread until it completes. If you must do a network check, use a cached value from the State Manager instead.
::
