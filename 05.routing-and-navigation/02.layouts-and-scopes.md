As your TUI application grows, you will encounter scenarios where multiple screens need to share the same outer boundary, such as a persistent Sidebar or a Top Navigation Bar.

If you try to import and render that Sidebar inside every component, you will end up with duplicated code. Tako provides **Layouts** (via `Root()`) and **Route Scopes** (via `Scope()`) to solve this architectural problem.

## Layouts using `Root()`

A Layout is a special component that acts as a container (or a shell) for other routes. When a route inside a Layout is active, the Router renders the Layout and injects the active route's content into it.

### 1. Creating a Layout Component
A layout component is a standard component, but it injects the UI Manager to request the active view string.

```go
type MainLayout struct {
    // fields...
}

func (l *MainLayout) Render() string {
    // Render persistent headers
    header := "[ Server Dash ] -- System Monitoring\n"
    
    // Render the active route's view dynamically
    content := ctx.UI().RenderView()
    
    // Render persistent footers
    footer := "\n[q] Quit | [b] Back"
    
    return header + content + footer
}
```

### 2. Registering Routes inside a Layout
To group routes under a layout, use the `Root()` method on the Router.

```go
func Boot(app contracts.Application) error {
    layout := components.NewMainLayout()

    // Group routes inside the layout
    app.Router().Root(layout, func(r contracts.Router) {
        r.Route("/dashboard", components.NewDashboard()).Name("dashboard")
        r.Route("/servers", components.NewServerList()).Name("servers")
        r.Route("/settings", components.NewSettings()).Name("settings")
    })

    return nil
}
```

When you navigate to `dashboard`, `servers`, or `settings`, the `MainLayout` will wrap them.

## Scoping Routes using `Scope()`

If your application has many routes, keeping track of manual path prefixes (like `/api/v1/...` or `/admin/...`) becomes tedious and error-prone. `Scope()` allows you to isolate a router instance under a shared URL prefix.

If our Server Dash has an "Admin" section, we can scope it:

```go
app.Router().Scope("/admin").Root(adminLayout, func(admin contracts.Router) {
    admin.Route("/users", components.NewAdminUsers()).Name("admin.users")     // Becomes /admin/users
    admin.Route("/billing", components.NewAdminBilling()).Name("admin.billing") // Becomes /admin/billing
})
```

### Chaining with Scopes
When you call `Scope()`, Tako returns a cloned Router instance. This allows you to chain middlewares or layouts that *only* apply to that specific scope without affecting the rest of your application.

```go
// Any route defined inside this scope will:
// 1. Have the "/admin" prefix attached.
// 2. Be wrapped by the adminLayout shell.
// 3. Be protected by the AuthMiddleware.
app.Router().
    Scope("/admin").
    Use(AuthMiddleware).
    Root(adminLayout, func(admin contracts.Router) {
        admin.Route("/dashboard", components.NewAdminDash()).Name("admin.dash")
    })
```

::tip
Scopes and Roots can be nested. You can place a `/settings` scope inside an `/admin` scope, each with their own layouts and middlewares. This provides granular control over building terminal interfaces.
::
