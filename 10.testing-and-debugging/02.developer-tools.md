Building terminal applications can be tedious if you have to manually kill and restart the process every time you make a change. Furthermore, debugging performance issues like
memory leaks or slow frame rates can be a nightmare in the terminal.

To solve this, Tako ships with powerful built-in developer tools: a **Hot-Reloading Watcher** and a **Live Profiler**.

## Hot-Reloading (`--watch`)

Tako includes a built-in file watcher that automatically recompiles and restarts your application whenever you save a file.

To use it, simply append the `--watch` flag when running your application:

```bash
go run main.go --watch
```

This will automatically monitor all `.go`, `.yml`, `.env`, `.json`, and `.html` files in the directory (and subdirectories) where `main.go` resides.

### Terminal Rescue

A common problem when building TUIs is that if your application panics, your terminal is left in a broken state (invisible cursor, alt-screen stuck, mouse tracking still active).

The Tako Watcher solves this perfectly! If your application crashes, the Watcher intercepts the exit and **forcefully resets the terminal state**, ensuring your terminal remains
usable.

### Advanced Watcher Options

You can specify exact directories to watch:

```bash
go run main.go --watch=views,../pkg
```

Or exclude specific directories:

```bash
go run main.go --watch --exclude=tmp,assets
```

*Note: The watcher is wrapped in a `//go:build !prod` constraint, meaning it is completely stripped from your final compiled production binary.*

## Live Profiler (`inspect`)

The Tako Profiler is a lightweight observability subsystem that runs alongside your application in development mode without blocking the main event loop.

It exposes a Unix socket that streams real-time metrics (like FPS, Memory, Goroutines, and Boot Time) and provides standard Go `pprof` endpoints.

### Connecting to the Profiler

To view the live metrics of your running application, open a **separate terminal window** and run the built-in `inspect` command:

```bash
go run main.go inspect
```

By default, the `inspect` command will automatically find and connect to the most recently launched Tako application. If the target application restarts (e.g., via the watcher),
the inspector will gracefully reconnect automatically!

### Profiling with `pprof`

Because the profiler exposes a Unix socket, you can use `curl` to capture standard Go profiles for deep analysis:

**Capture a CPU Profile (30 seconds)**

```bash
curl --unix-socket ~/.tako/run/[pid].sock http://localhost/debug/pprof/profile?seconds=30 > cpu.prof
go tool pprof cpu.prof
```

**Capture a Heap (Memory) Profile**

```bash
curl --unix-socket ~/.tako/run/[pid].sock http://localhost/debug/pprof/heap > heap.prof
go tool pprof heap.prof
```

*(You can find the socket `[pid]` by looking at the `.tako/run/` directory).*
