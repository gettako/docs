While Tako is primarily a TUI framework, every enterprise terminal application eventually needs to support standard, headless CLI commands (like `go run main.go migrate` or `go run main.go serve --port 8080`).

Writing raw `flag.Parse()` scripts scattered around your codebase is difficult to test. Tako integrates a Command Line Interface registry directly into the core, allowing you to use the exact same IoC Container, Configuration, and Path Handling for headless CLI scripts without writing boilerplate.

## The `Command` Interface

All commands in Tako must implement the `contracts.Command` interface. This encourages you to separate your command logic into strictly isolated, testable structs.

```go
type Command interface {
    // Signature defines how the command is invoked (e.g., "db:seed {--f|force}").
    Signature() string

    // Description provides the helpful text shown in the CLI help list.
    Description() string

    // Handle contains the actual execution logic.
    Handle(ctx CommandContext) error
}
```

## Creating a Command

Let's create a `db:seed` command that populates our local database.

```go [internal/console/commands/seed.go]
package commands

import (
    "gettako.dev/tako/contracts"
)

type SeedCommand struct{}

func (c *SeedCommand) Signature() string { 
    // The signature uses a Laravel-style definition
    return "db:seed {count=10} {--f|force : Force seed without prompt}" 
}

func (c *SeedCommand) Description() string {
    return "Seed the database with dummy data"
}

func (c *SeedCommand) Handle(ctx contracts.CommandContext) error {
    // 1. Read input easily
    count := ctx.Argument("count")
    force := ctx.Option("force")

    // 2. Check flags
    if !force {
        if !ctx.Confirm("Are you sure you want to seed the database?") {
            ctx.Warn("Seeding aborted.")
            return nil
        }
    }

    // 3. Output blocks
    ctx.Components().Info("Starting database seeder...")

    // 4. Resolve dependencies from the container
    var db contracts.Database
    if err := ctx.Container().Make(&db); err != nil {
        ctx.Components().Fail("Failed to connect to Database!")
        return err
    }

    // ... Seed Database here ...

    ctx.Components().Done("Database seeded successfully.")
    return nil
}
```

## Registering Commands

Once your struct is created, you explicitly register it to the `CliRegistry` during the `Boot` phase of a Service Provider (usually a `ConsoleProvider` or `CliProvider`).

```go [internal/providers/cli_provider.go]
package providers

import (
    "gettako.dev/tako/contracts"
    "myproject/internal/console/commands"
)

type CliProvider struct{}

func (p *CliProvider) Register(app contracts.Application) error { return nil }

func (p *CliProvider) Boot(app contracts.Application) error {
    // Register your commands here
    app.CliRegistry().Register(&commands.SeedCommand{})
    
    return nil
}
```

## Command Output & Formatting

Tako provides multiple ways to print to the console. You should **always** use the `CommandContext` rather than `fmt.Println` to ensure your text doesn't corrupt the terminal state.

### Laravel-Style Components
For block alerts (heavily inspired by Laravel Prompts), use `ctx.Components()`:

```go
ctx.Components().Info("Application successfully booted.")
ctx.Components().Warn("Running in debug mode!")
ctx.Components().Fail("Failed to connect to database.")
ctx.Components().Done("Migration completed successfully.")
```

### Standard Output
For standard colored line output:

```go
ctx.Info("This is informational text (Green)")
ctx.Warn("This is warning text (Yellow)")
ctx.Fail("This is error text (Red)")
ctx.Done("This is success text (Bold Green)")
ctx.Line("This is a standard unformatted line.")
ctx.NewLine(2) // Print 2 blank lines
```

### Inline XML-like Styling
Tako includes an inline parser that removes the need to concatenate terminal escape codes. You format text using XML tags.

```go
ctx.Line("Start processing <in>file <it>config.yml</></> with <da bl>danger</>!")
ctx.Line("You can nest tags: <bg:wa in it> Italic Info text on a Warning Background </></>")
```

Available inline tags:
- **Foregrounds**: `<pr>` (primary), `<su>` (success), `<in>` (info), `<wa>` (warning), `<da>` (danger)
- **Backgrounds**: `<bg:pr>`, `<bg:su>`, `<bg:in>`, `<bg:wa>`, `<bg:da>`
- **Modifiers**: `<bo>` (bold), `<it>` (italic), `<un>` (underline), `<bl>` (blink)
- **Clear**: `</>` (resets styles back to normal)

### Prompts
You can interact with the user via formatted prompts:

```go
name := ctx.Ask("What is your name?")

if ctx.Confirm("Do you like Tako?") {
    ctx.Done("Thanks!")
}
```
