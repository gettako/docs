Out of the box, Tako provides several built-in, headless CLI commands designed to improve your developer experience and assist with troubleshooting.

Because Tako's command router handles both TUI booting and headless CLI commands, you can invoke these tools directly by passing arguments to your application binary or `go run` command.

## 1. The `help` Command

If you forget what commands are available in your application, or want to see the flags supported by a specific command, use the `help` command.

```bash
go run main.go help
```

This will output a formatted, color-coded list of all registered commands, combining your custom scripts with Tako's built-in tools.

To get help on a specific command:
```bash
go run main.go my:custom-command --help
```

## 2. The `inspect` Command

As discussed in the Developer Tools section, debugging a live TUI application can be difficult. The `inspect` command solves this by connecting to your running TUI via the RPC Bus.

```bash
go run main.go inspect
```

**Requirements:**
- Your primary TUI application must be running in another terminal window.
- The RPC Provider must be enabled (enabled by default when using `tako.NewApp()`).

The Inspector will present a live dashboard showing memory metrics, active routes, state changes, and a real-time stream of all events firing across the Event Bus.

## 3. The `doctor` Command

If your application refuses to boot or is behaving strangely on a new machine, the `doctor` command automatically runs a suite of diagnostic checks on your environment.

```bash
go run main.go doctor
```

**What it checks:**
1. **App Info:** Verifies the current Tako version, environment (`local`/`production`), and whether Debug Mode is active.
2. **OS & Go Environment:** Checks the underlying Operating System, Architecture, and Go Version.
3. **Color Support:** Tests the `TERM` and `COLORTERM` environment variables to ensure the terminal supports true-color output.
4. **Working Directory:** Verifies the application is running in a valid, accessible directory.
5. **Nerd Font Compatibility:** Outputs a series of Nerd Font icons to visually confirm if the user's terminal font supports ligatures and icons.

## 4. The `build` Command

To compile your Tako application for production, you must explicitly use Go build tags to exclude development-only packages. Tako provides a handy command to automate this chore:

```bash
go run main.go build
```

If you prefer building it manually, you **must** pass the `prod` tag:
```bash
go build -tags prod -o serverdash main.go
```

::warning
Failing to include the `prod` tag will cause developer tools (such as the Profiler server and hot-reloading watcher) to be compiled directly into your release, which is a severe security and performance risk.
::

## 5. The `--watch` Flag (Hot Reloading)

While not strictly a standalone command, Tako supports an experimental `--watch` flag that enables Hot Reloading during rapid development.

Instead of running your app directly with `go run`, you simply run:

```bash
go run main.go --watch
```

It supports hot-reloading for headless CLI commands as well:
```bash
go run main.go my:custom-command --watch
```

When started with this flag, Tako actively monitors your `internal/` and `contracts/` directories for file changes. If it detects a change, it will automatically rebuild and restart the TUI application or CLI command, saving manual compilation time.

::note
The `--watch` flag requires `go` to be installed and available in your system's PATH. It is exclusively meant for local development and will be ignored if passed to a compiled release binary.
::
