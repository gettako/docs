TUI apps are notoriously hard to test because they assume control of the terminal. Tako avoids this by separating logic from rendering. The service container makes mocking trivial,
providers initialize without an active UI, and keybindings are pure functions you can invoke programmatically.

## Testing a Provider

A provider's `Boot` receives a `*foundation.Application`. You can construct a minimal application with a real container, call `Boot`, and verify the side effects:

```go [providers/orders/provider_test.go]
package orders_test

import (
	"testing"

	"gettako.dev/tako/contracts"
	"gettako.dev/tako/internal/tako"
	"gettako.dev/tako/pkg/container"
	"gettako.dev/tako/pkg/event"
	"gettako.dev/tako/pkg/foundation"
)

func TestOrderProvider_EmitsOnCreate(t *testing.T) {
	// 1. Setup container and bus
	c := container.New()
	bus := event.NewBus()
	c.Singleton(new(contracts.EventBus), bus)

	app := tako.NewApp(tako.WithContainer(c))

	// 2. Boot provider
	provider := &OrderProvider{}
	if err := provider.Boot(app); err != nil {
		t.Fatal(err)
	}

	// 3. Spy on events
	var received contracts.Event
	bus.On("order:created", func(e contracts.Event) {
		received = e
	})

	// 4. Trigger action
	provider.createOrder("CUST-123", 50.0)

	// 5. Assert
	if received.Name != "order:created" {
		t.Errorf("expected order:created, got %q", received.Name)
	}
}
```

## Testing Keybindings

You can verify keybindings trigger the correct logic by calling `HandleKey` directly on the router:

```go [providers/orders/navigation_test.go]
func TestJKey_MovesDown(t *testing.T) {
    r := router.NewRouter(func() {}, nil)
    r.Stack().Push("order-list")

    moved := false
    r.Registry().RegisterZone(0, "order-list", "j", func() {
        moved = true
    })

    r.Focus(0, "order-list")
    r.HandleKey("j")

    if !moved {
        t.Error("expected 'j' to trigger move down")
    }
}
```

No adapter or terminal needed. The router is just a mapping of strings to functions.

## Testing Commands

CLI commands are structs with an `Execute` method. Call it directly:

```go [commands/export_test.go]
func TestExportCommand_RequiresTarget(t *testing.T) {
    cmd := &ExportCommand{}
    ctx := &cli.Context{} // Pass a minimal context

    err := cmd.Execute(ctx, []string{})
    if err == nil {
        t.Error("expected error when no target is provided")
    }
}
```

## Mocking Services

Because providers resolve dependencies from the container, swapping a real service for a mock is a one-liner:

```go [test_helpers.go]
// In your test setup:
c.Singleton(new(*APIClient), &MockAPIClient{
    FetchFunc: func(id string) (*Order, error) {
        return &Order{ID: id, Total: 99.99}, nil
    },
})
```

Your provider asks the container for `*APIClient` and receives the mock automatically.

## Headless Integration Testing

To test the full application stack (bootstrap + providers + rendering) without a terminal, register a headless adapter:

```go [test_adapter.go]
type TestAdapter struct {
    Frames []string
}
func (a *TestAdapter) Render() error { return nil }
func (a *TestAdapter) Stop() error   { return nil }
```

```go [integration_test.go]
func TestApp_BootsCleanly(t *testing.T) {
    app := tako.NewApp()
    app.Mount(&TestAdapter{})

    if err := tako.Run(app); err != nil {
        t.Fatal(err)
    }

    // Assert container state, provider registration, etc.
}
```

::tip
Use `Transient` bindings for stateful services in your tests to ensure a fresh instance per test case, preventing cross-test pollution.
::
