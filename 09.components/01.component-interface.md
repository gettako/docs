A component bundles rendering, keybindings, and identity into one portable struct. Call `MountOverlay` and Tako handles overlay push, key registration, focus shift, and hook
registration — all at once.

## The Interface

```go [contracts/component.go]
type Component interface {
    ID() string            // Layer ID + default focus zone name
    Render() any           // Called every frame; return any type your layout understands
    RegisterKeys(KeyManager) // Declare bindings scoped to this component's zone
}
```

## A Complete Component

```go [components/order_search.go]
package components

import (
	"strings"

	"gettako.dev/tako/contracts"
)

type OrderSearchBox struct {
	query     string
	results   []*Order
	allOrders []*Order
	selected  int
	onSelect  func(*Order)
	onDismiss func()
}

func NewOrderSearch(orders []*Order, onSelect func(*Order), onDismiss func()) *OrderSearchBox {
	return &OrderSearchBox{
		allOrders: orders,
		results:   orders,
		onSelect:  onSelect,
		onDismiss: onDismiss,
	}
}

func (s *OrderSearchBox) ID() string { return "order-search" }

func (s *OrderSearchBox) Render() any {
	// Return a struct your layout knows how to render
	// Render() may be called 60 times/sec — never compute here, only return cached state
	return &OrderSearchView{
		Query:    s.query,
		Results:  s.results,
		Selected: s.selected,
	}
}

func (s *OrderSearchBox) RegisterKeys(km contracts.KeyManager) {
	// Component-level keys — active whenever this component is on top
	km.Bind("esc", func() { s.onDismiss() })
	km.Bind("enter", func() {
		if s.selected < len(s.results) {
			s.onSelect(s.results[s.selected])
		}
	})
	km.Bind("backspace", func() {
		if len(s.query) > 0 {
			s.query = s.query[:len(s.query)-1]
			s.filter()
		}
	})

	// Zone-scoped keys for the results list
	results := km.Zone("order-search-results")
	results.Bind("j|down", func() {
		if s.selected < len(s.results)-1 {
			s.selected++
		}
	})
	results.Bind("k|up", func() {
		if s.selected > 0 {
			s.selected--
		}
	})
}

func (s *OrderSearchBox) filter() {
	if s.query == "" {
		s.results = s.allOrders
		return
	}
	q := strings.ToLower(s.query)
	s.results = s.results[:0]
	for _, o := range s.allOrders {
		if strings.Contains(strings.ToLower(o.ID), q) ||
			strings.Contains(strings.ToLower(o.CustomerName), q) {
			s.results = append(s.results, o)
		}
	}
	if s.selected >= len(s.results) {
		s.selected = 0
	}
}
```

## Showing a Component

```go [providers/orders/provider.go]
func (p *OrderProvider) openSearch(ctx *tako.Context) {
    search := components.NewOrderSearch(
        p.orders,
        func(order *Order) {
            p.openDetail(order)
            ctx.UI().Unmount()
        },
        func() {
            ctx.UI().Unmount()
        },
    )
    ctx.UI().MountOverlay(search)
}
```

`MountOverlay` does all of this in one call:

1. Calls `ID()` — uses the return value as the layer ID and focus zone
2. Calls `RegisterKeys(km)` with a `KeyManager` pre-scoped to the component's stack level
3. Pushes layer `"order-search"` onto the focus stack
4. Registers `Render()` as a hook provider at `"tako.overlay.order-search"`
5. Shifts focus to the `"order-search"` zone

## Pre-Registration

For components that are shown repeatedly (command palette, global search), pre-register during `OnInit` to avoid setup latency at show time:

```go [providers/orders/provider.go]
func (p *OrderProvider) Boot(app *foundation.Application) error {
    // Keys wired, hook ready — layer not pushed yet
    p.searchBox = components.NewOrderSearch(p.orders, p.selectOrder, p.closeSearch)
    app.UI().Register(p.searchBox)
    return nil
}

// Later, from a key handler:
func (p *OrderProvider) openSearch(ctx *tako.Context) {
    ctx.UI().Show("order-search", p.searchBox.Render) // No registration delay
}
```

## KeyManager Interface

```go [contracts/key_manager.go]
type KeyManager interface {
    Bind(key string, handler func())
    Zone(name string, level ...int) ZoneKeyManager
}

type ZoneKeyManager interface {
    Bind(key string, handler func())
}
```

**Zones within a component** are useful when the component has multiple interactive regions that might use the same key for different purposes:

```go [components/split_panel.go]
func (p *SplitPanel) RegisterKeys(km contracts.KeyManager) {
    km.Bind("tab", func() { p.switchPane() })

    left := km.Zone("left-panel")
    left.Bind("j", func() { p.scrollLeft(1) })
    left.Bind("k", func() { p.scrollLeft(-1) })

    right := km.Zone("right-panel")
    right.Bind("j", func() { p.scrollRight(1) })
    right.Bind("k", func() { p.scrollRight(-1) })
}
```

Both `"left-panel"` and `"right-panel"` can bind `j` — they're separate zones and only one is focused at a time.

## NativeComponent & Bubble Tea Interop

If you are using the Bubble Tea adapter and want to use components from the broader Charm ecosystem (like `bubbles/textinput`), your component can implement `NativeComponent` to
receive raw `tea.Msg` events directly.

```go [contracts/component.go]
type NativeComponent interface {
    Component
    UpdateNative(msg any) (any, any) // msg is tea.Msg, returns (tea.Model, tea.Cmd)
}
```

When a `NativeComponent` is active, the adapter will automatically forward any events (like keystrokes or mouse events) that were **not consumed by the Router** directly to
`UpdateNative`.

::tip
Keep `Render()` pure — return a value object that the layout renders. Never format strings in `Render()` if the same string might be needed in other contexts (tests, different
layouts). Separate the data structure from the presentation: `Render()` returns `*OrderSearchView`, the layout converts it to a terminal string. This makes components testable
without a terminal.
::
