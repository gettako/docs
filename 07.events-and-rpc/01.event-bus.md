As your application grows, you will inevitably run into situations where one component needs to tell another component that "something happened," but you don't want those
components tightly coupled to each other.

Tako provides a robust, thread-safe Event Dispatcher (or Event Bus) to solve this exact problem. It allows components to subscribe to events and dispatch events entirely
anonymously.

## Registering Listeners

To listen for an event, use the `Listen` method on the Event Dispatcher. The method takes the name of the event and a handler function. The handler function will be executed
synchronously whenever the event is dispatched, receiving the generic `payload`.

You can register listeners globally inside a [Service Provider](/architecture-concepts/providers), or locally inside a View component.

```go
func (p *AppProvider) Boot(app contracts.Application) {
	app.Events().Listen("user:created", func(payload any) {
		user := payload.(User)
		app.Logger().Info("A new user was created: " + user.Name)
	})
}
```

::note
By convention, event names in Tako use colon notation (e.g., `module:action`). Dot notation is strictly reserved for configurations.
::

### Canceling Listeners (Memory Safety)

When you call `Listen()`, it returns a **cancel function**. This is an incredibly important feature for building long-running TUI applications!

If you register an event listener inside a component that is frequently created and destroyed (like a temporary UI modal or a dynamic screen), you **must** cancel the listener when
the component is destroyed. Otherwise, your application will suffer from a memory leak, as the dispatcher will hold onto the closure forever.

Tako handles cancellation using an ultra-efficient O(1) swap-remove algorithm internally, so you never have to worry about performance drops when unregistering.

```go
type TemporaryScreen struct {
	cancelEvent func()
}

func (s *TemporaryScreen) OnEnter() { // Uses RouterMiddleware
	// Save the cancel function!
	s.cancelEvent = app.Events().Listen("data:updated", func(payload any) {
		// handle update...
	})
}

func (s *TemporaryScreen) OnLeave() {
	// Execute the cancel function to free memory in O(1) time
	if s.cancelEvent != nil {
		s.cancelEvent()
	}
}
```

### Wildcard Listeners

You can listen to *all* events dispatched across the entire application by registering a wildcard listener (`*`).

When you use a wildcard listener, the payload you receive will be of type `contracts.WildcardEvent`, which contains both the name of the original event and its payload.

```go
app.Events().Listen("*", func(payload any) {
	event := payload.(contracts.WildcardEvent)
	app.Logger().Debug("Fired Event: " + event.Name)
})
```

## Dispatching Events

To trigger an event, use the `Dispatch` method. The first argument is the name of the event, and the second is the payload. The payload can be absolutely anything (a string, a
struct, a map, or just `nil`).

```go
type UserController struct {
	events contracts.EventDispatcher
}

func (c *UserController) Store() {
	// ... database logic ...

	// Let the rest of the application know!
	c.events.Dispatch("user:created", newUser)
}
```

### System Events

Tako's internal architecture also dispatches events that you can listen to!

* `app.booted`: Dispatched when the application finishes booting (receives a map of boot time metrics).
* `system:log`: Dispatched every time the logger writes a line.
* `router:navigated`: Dispatched when the router changes screens.
