Tako's adapter architecture supports custom rendering backends as a first-class feature. The `UIRenderer` interface is minimal, and the `BaseAdapter` provides the event bus,
routing, and profiling infrastructure for free.

## The Interface

Every adapter must satisfy this contract:

```go [contracts/renderer.go]
type UIRenderer interface {
    Render() error // Init terminal, block until exit
    Stop() error   // Restore terminal state
}
```

## Embedding BaseAdapter

Embed `BaseAdapter` to handle the heavy lifting (event bus flushing, routing, profiling):

```go [adapter/tcell/adapter.go]
import "gettako.dev/tako/pkg/adapter/ui"

type TcellAdapter struct {
    ui.BaseAdapter
    screen tcell.Screen
    ctx    *tako.Context
    done   chan struct{}
}

func NewAdapter(ctx *tako.Context) (*TcellAdapter, error) {
    screen, err := tcell.NewScreen()
    if err != nil {
        return nil, err
    }
    return &TcellAdapter{
        BaseAdapter: ui.NewBaseAdapter(ctx),
        screen:      screen,
        ctx:         ctx,
        done:        make(chan struct{}),
    }, nil
}
```

## Input Translation

Convert the rendering framework's native inputs to Tako's strings, then pass them to the base adapter:

```go [adapter/tcell/keys.go]
func tcellKeyToTako(ev *tcell.EventKey) string {
    switch ev.Mutate() {
    case tcell.KeyCtrlC: return "ctrl+c"
    case tcell.KeyEnter: return "enter"
    case tcell.KeyEscape: return "esc"
    case tcell.KeyUp: return "up"
    // ...
    }
    return ""
}
```

## The Render Loop

`StartEventLoop` spins up a background goroutine that polls the event bus at 60fps and calls your callback when events are pending.

```go [adapter/tcell/adapter.go]
func (a *TcellAdapter) Render() error {
    a.screen.Init()
    defer a.screen.Fini()

    a.InitProfiler()

    // Trigger redraw when bus events arrive
    a.StartEventLoop(a.ctx, 16*time.Millisecond, func(events []contracts.Event) {
        a.draw()
    })

    // Initial draw
    a.draw()

    // Blocking input loop
    return a.eventLoop()
}

func (a *TcellAdapter) eventLoop() error {
    for {
        ev := a.screen.PollEvent()
        switch ev := ev.(type) {
        case *tcell.EventKey:
            if key := tcellKeyToTako(ev); key != "" {
                a.HandleKey(key)
                a.draw()
            }
        }
    }
}
```

## Registration

Register your custom adapter in `main.go`:

```go [main.go]
func main() {
    app := tako.NewApp()

    adapter, err := tcellAdapter.NewAdapter(app.Context())
    if err != nil {
        log.Fatalf("failed to create adapter: %v", err)
    }

    app.Mount(adapter)
    tako.Run(app)
}
```

## Headless Test Adapters

A headless adapter exercises UI logic without drawing to a real terminal:

```go [adapter/testing/adapter.go]
type TestAdapter struct {
    ui.BaseAdapter
    ctx *tako.Context
}

func (a *TestAdapter) Render() error { return nil }
func (a *TestAdapter) Stop() error   { return nil }

func (a *TestAdapter) SimulateKey(key string)  { a.HandleKey(key) }
func (a *TestAdapter) ProcessEvents() []contracts.Event { return a.FlushEvents() }
```

```go [plugins/orders/plugin_test.go]
func TestOrderSelection(t *testing.T) {
    app := tako.NewApp()
    adapter := testAdapter.NewTestAdapter(app.Context())
    app.Mount(adapter)

    adapter.SimulateKey("j")
    adapter.SimulateKey("enter")

    events := adapter.ProcessEvents()
    // Assert on events...
}
```
