In Tako, everything you see on the terminal screen is a **View** (also commonly referred to as a Component or Screen).

If you are coming from raw Bubble Tea, a View in Tako replaces the concept of a Bubble Tea `Model`. However, Tako dramatically simplifies the interface to make building UIs cleaner
and more declarative.

## The View Contract

To create a View, you only need to implement a single method from the `contracts.View` interface: `Render`.

```go
package components

import "gettako.dev/tako/contracts"

type WelcomeScreen struct {}

func (s *WelcomeScreen) Render(ctx contracts.Context) string {
	return "Welcome to the application!"
}
```

That's it! You do not need to implement `Init()` or `Update()` if your component is just displaying text.

The `Render` method receives a `contracts.Context` which contains the global application state, and it must return a `string` representing what should be drawn on the screen. (You
can use [Lip Gloss](https://github.com/charmbracelet/lipgloss) here to style your strings!).

## Displaying a View (Without a Router)

If your application is very simple and only consists of a single screen, you don't even need to set up the Router! You can tell Tako to render your View directly by setting it as
the **Root** of the TUI Kernel in your `main.go` file.

```go
func main() {
	app := tako.NewApp()

	// Tell the TUI Engine to render this view directly
	app.TUI().Root(&WelcomeScreen{})

	tako.Run(app)
}
```

This is the absolute simplest way to build a Tako app. However, if you need multiple screens (like navigating from Home to Settings), you will want to use
the [Router](/the-basics/routing).

## Handling Input (Optional)

In vanilla Bubble Tea, all input goes through a giant `switch msg := msg.(type)` block inside the `Update` method.

Tako uses a much cleaner, specialized approach. If your View needs to listen to keyboard shortcuts, you simply implement the **`contracts.KeyBinder`** interface by adding a
`Keys()` method.

```go
package components

import "gettako.dev/tako/contracts"

type CounterScreen struct {
	count int
}

func (s *CounterScreen) Render(ctx contracts.Context) string {
	return fmt.Sprintf("Count: %d\n\nPress '+' to increment, '-' to decrement.", s.count)
}

// Implementing contracts.KeyBinder
func (s *CounterScreen) Keys(km contracts.InputManager) {
	km.Bind("+", func(ctx contracts.InputContext) {
		s.count++
	})

	km.Bind("-", func(ctx contracts.InputContext) {
		s.count--
	})
}
```

Tako will automatically register these keybindings when your View becomes active (e.g., when the router navigates to it) and automatically unregister them when you leave the
screen. You don't have to manage any state!

## Handling Raw Messages (Optional)

Sometimes you really *do* need access to the raw Bubble Tea messages. For example, if you are embedding a native `textinput.Model` from the `bubbles` library and need to pass
typing events to it.

For these cases, your component can implement the **`contracts.MessageHandler`** interface by adding an `Update(msg any) bool` method.

```go
import "github.com/charmbracelet/bubbles/textinput"

type FormScreen struct {
	input textinput.Model
}

// Implementing contracts.MessageHandler
func (s *FormScreen) Update(msg any) bool {
    var cmd tea.Cmd
    s.input, cmd = s.input.Update(msg)
    
    // Return true to tell Tako to re-render the screen
    return true 
}
```

Notice that `Update` in Tako returns a `bool` instead of `(Model, Cmd)`. You simply return `true` if the state changed and you want Tako to trigger a re-render.

## Mouse Click Actions (Optional)

Tako includes deep integration with [BubbleZone](https://github.com/lrstanley/bubblezone) to make terminal elements clickable.

If your component needs to handle mouse clicks on specific regions, you implement the **`contracts.ActionHandler`** interface.

::note
We highly recommend using Tako's internal `view.BaseComponent` (or creating your own base struct) to handle the complex ID generation and mouse coordinate tracking automatically
instead of writing the boilerplate yourself.
::
