By default, Tako ships with an adapter for [Bubbletea](https://github.com/charmbracelet/bubbletea). However, Tako's architecture is decoupled from the rendering engine. 

If you want to use a different library (like `tcell` or `gocui`)—or build your own rendering engine from scratch—you need to write a Custom UI Adapter.

## The `UIManager` Interface

A UI Adapter in Tako needs to implement the `contracts.UIManager` interface.

```go
type UIManager interface {
    // Start kicks off the blocking event loop (e.g., tea.Program.Run or tcell's PollEvent loop).
    Start(ctx context.Context) error

    // RequestRender signals the adapter that the application state has changed 
    // and it should draw the next visual frame.
    RequestRender()

    // Stop halts the rendering loop and restores the terminal to its original state.
    Stop()

    // RenderView provides the adapter with the active component string.
    // The Router uses this to inject the layout.
    RenderView() string
}
```

## Step 1: Create the Adapter Struct

Let's create a hypothetical `TcellAdapter`. It needs to hold a reference to the Tako Application and the underlying `tcell.Screen`.

```go [tcell_adapter.go]
package adapter

import (
    "context"
    "gettako.dev/tako/contracts"
    "github.com/gdamore/tcell/v2"
)

type TcellAdapter struct {
    app    contracts.Application
    screen tcell.Screen
    view   string
}

// Ensure it implements the interface at compile time
var _ contracts.UIManager = (*TcellAdapter)(nil)

func NewTcellAdapter(app contracts.Application) *TcellAdapter {
    return &TcellAdapter{app: app}
}
```

## Step 2: Implement the Methods

### Start()
This is where you initialize the underlying library and start its event loop. You must listen for keyboard and mouse events and route them to Tako's `InputManager` and `MouseRegistry`.

```go
func (a *TcellAdapter) Start(ctx context.Context) error {
    s, err := tcell.NewScreen()
    if err != nil { return err }
    
    if err := s.Init(); err != nil { return err }
    a.screen = s

    // Start the event loop in the background
    go func() {
        for {
            select {
            case <-ctx.Done():
                // Listen to the shutdown context
                return
            default:
                ev := a.screen.PollEvent()
                switch ev := ev.(type) {
                case *tcell.EventKey:
                    // Route the raw key directly to Tako
                    keyName := ConvertTcellKeyToString(ev)
                    a.app.Input().HandleKey(keyName)
                }
            }
        }
    }()

    // Wait until the global context is cancelled
    <-ctx.Done()
    return nil
}
```

### RequestRender()
When a component calls `ctx.RenderNow()`, Tako triggers this method. Here you ask Tako for the current view and draw it to the screen.

```go
func (a *TcellAdapter) RequestRender() {
    // 1. Get the current active component from the router
    activeComponent := a.app.Router().ActiveComponent()
    if activeComponent == nil { return }
    
    // 2. Call Render() on the component to get the string
    a.view = activeComponent.Render()
    
    // 3. Draw a.view to the terminal using tcell
    a.screen.Clear()
    DrawStringToScreen(a.screen, a.view)
    a.screen.Show()
}
```

### RenderView() & Stop()
```go
func (a *TcellAdapter) RenderView() string {
    return a.view
}

func (a *TcellAdapter) Stop() {
    if a.screen != nil {
        a.screen.Fini() // Restore the user's terminal
    }
}
```

## Step 3: Injecting Your Adapter

Once your adapter is built, you inject it into the Tako application before running it:

```go [main.go]
app := tako.NewApp()

// Inject our custom Tcell Adapter
adapter := NewTcellAdapter(app)

app.Mount(adapter)

tako.Run(app)
```
