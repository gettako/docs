Forget everything you know about building terminal applications. 

What if you could build a TUI dashboard the exact same way you build a modern website? No more calculating X and Y coordinates. No more endless `+` string concatenations. No more crying over raw ANSI escape codes.

Tako introduces the **Reactive HTML Engine**: a paradigm shift that brings the joy of **Vue**, **Alpine.js**, and **TailwindCSS** directly into your terminal. You write standard, declarative HTML, and Tako natively compiles it into a beautiful, interactive TUI.

## Separation of Concerns

The engine separates your component into two files:
1. **The Logic (`counter.go`)**: A standard Go struct containing your state and methods.
2. **The View (`counter.html`)**: The HTML template containing the layout, styles, and event bindings.

### 1. The Go Component (`counter.go`)

In your Go file, you define the state and any methods that manipulate that state. Notice how the `Render` method simply returns `ctx.View("counter.html")`.

```go
package components

import (
	"gettako.dev/tako/contracts"
)

type Counter struct {
	Count int
}

// Render tells Tako to parse and render the HTML file
func (c *Counter) Render(ctx contracts.Context) contracts.ViewNode {
	return ctx.View("counter.html")
}

// These methods can be triggered directly from the HTML!
func (c *Counter) Increment(amount int) {
	c.Count += amount
}

func (c *Counter) Decrement(amount int) {
	c.Count -= amount
}
```

### 2. The HTML View (`counter.html`)

Now, let's look at the HTML template. Notice the Tailwind-like utility classes, the Alpine-style event bindings (`@keyup:enter`), and the Vue-like dynamic classes (`:class`).

```html
<div class="border border-[#4b5563] p-1 w-20 text-center">
    <div class="font-bold fg-[#cb6843]">Counter</div>
    
    <!-- Dynamic class bindings and state interpolation -->
    <div class="text-xl" :class="{ 'fg-[#cb6843]': Count >= 0, 'fg-[#dc2626]': Count < 0 }">
        {{ Count }}
    </div>
    
    <div class="flex space-x-1 justify-center mt-1">
        <!-- Interactive buttons with focus states and keybindings -->
        <div focusable 
             @keyup:enter="Increment(2)" 
             class="px-1 border border-[#4b5563] fg-[#16a34a] focus:bg-[#16a34a] focus:fg-[#ffffff]">
            +1
        </div>
        
        <div focusable 
             @keyup:enter="Decrement(2)" 
             class="px-1 border border-[#4b5563] fg-[#dc2626] focus:bg-[#dc2626] focus:fg-[#ffffff]">
            -1
        </div>
    </div>
</div>
```

## Styling (Tailwind for the Terminal)

Tako supports utility classes inspired by TailwindCSS, translating them directly into terminal rendering instructions under the hood.

- **Colors**: Use hex codes for foreground `fg-[#cb6843]` and background `bg-[#ffffff]`.
- **Layout**: `flex`, `space-x-1`, `justify-center`.
- **Spacing**: `p-1`, `px-1`, `mt-1`.
- **Borders**: `border`, `border-[#hex]`.
- **Typography**: `font-bold`, `text-center`, `text-xl`.

### Focus Management & Tab Order

You can easily handle interaction states and keyboard navigation without writing a single line of Go. By adding the `focusable` attribute to an element, it becomes a target for the keyboard.

::tip
**Tab Navigation built-in!**
Users can press `Tab` and `Shift+Tab` to move between any elements marked as `focusable`.
::

There are two ways to control the focus order:

1. **Natural Order (`focusable`)**: The engine will automatically focus elements in the exact order they appear in the HTML tree from top to bottom.
2. **Manual Order (`focusable="3"`)**: Similar to HTML's `tabindex`, you can explicitly define the order. The engine will focus elements starting from `1` upwards.

```html
<!-- Natural Order -->
<div focusable class="...">Button A</div>
<div focusable class="...">Button B</div>

<!-- Manual Order -->
<div focusable="2" class="...">This gets focused second</div>
<div focusable="1" class="...">This gets focused first!</div>
```

Once an element is focused, you can apply specific styles using the `focus:` pseudo-class:

```html
<div focusable class="border fg-[#16a34a] focus:bg-[#16a34a] focus:fg-[#ffffff]">
    Hover me with your keyboard!
</div>
```

## Event Bindings

Registering keyboard and mouse inputs directly in HTML is extremely powerful.

```html
<!-- Trigger method on Enter key -->
<div @key:enter="submit()">

<!-- Global keybinding (works even if the element is not focused) -->
<div @key:enter.global="submit()">

<!-- Modifiers (e.g., prevent spam clicking) -->
<div @click.debounce="submit()">
```

## Directives & Control Structures

Tako's HTML parser supports advanced Vue/Alpine style directives and Blade-like templating for complex logic.

### Conditionals (`x-if` and Blade syntax)
```html
<!-- Alpine style -->
<div x-if="Count > 10">You reached the limit!</div>

<!-- Blade / Go Template style -->
{{ if Count > 10 }}
    <div>You reached the limit!</div>
{{ end }}
```

### Loops (`x-for`)
```html
<div x-for="item in Items">
    <div x-text="item.Name"></div>
</div>
```

### Object Traversal (`x-foo.bar`)
You can easily traverse nested data structures within your state:
```html
<div x-text="User.Profile.Avatar"></div>
```

### Component Slots
Just like Vue or Web Components, you can compose components together using slots.
```html
<!-- Inside a Card layout component -->
<div class="border p-2">
    <slot name="header"></slot>
    <div class="card-body">
        <slot></slot> <!-- Default slot -->
    </div>
</div>
```

With Tako's Reactive HTML Engine, building TUIs is no longer an arcane art of string manipulation. It is as joyful and productive as modern frontend web development!
