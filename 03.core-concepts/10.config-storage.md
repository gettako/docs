## The `.tako` Home Directory

Before loading config, storage, or logs, Tako must determine where the `.tako` directory is located. This is resolved by `tako.GetHomeDir()` in the following priority order:

1. **`TAKO_APP_DIR` (Project-local)**: If this environment variable is set (or automatically detected during App Initialization), Tako will use `<TAKO_APP_DIR>/.tako`. This is the default behavior for local development.
2. **`TAKO_HOME` (Explicit override)**: If you set `TAKO_HOME`, Tako uses that exact path (e.g., `TAKO_HOME=/var/lib/myapp`).
3. **User Home Directory (Global fallback)**: If neither is set, Tako falls back to `~/.tako` in the user's home directory.

## Configuration

Tako's config system is deliberately minimal. It's a flat key-value store loaded from a JSON file, with environment variable overrides. By default, Tako looks for `.tako/config.json`.

```json
{
  "app": {
    "debug": true,
    "name": "My App"
  },
  "search": {
    "max_results": 50
  }
}
```

Nested objects are flattened to dot-notation keys: `app.debug` → `true`.

### Reading Config

Config is read-only. Plugins cannot write to config at runtime.

```go [plugin.go]
func (p *Plugin) OnInit(ctx *tako.Context) error {
    cfg := ctx.Config()
    
    // Read with default fallback if missing
    debug := cfg.Bool("app.debug", false)
    name := cfg.String("app.name", "Default App Name")
    maxResults := cfg.Int("search.max_results", 50)
    
    return nil
}
```

### Environment Variable Overrides

Any config key can be overridden with an environment variable using the `TAKO_` prefix. Dots are replaced by underscores:
- `app.debug` → `TAKO_APP_DEBUG=true`
- `search.max_results` → `TAKO_SEARCH_MAX_RESULTS=100`

## KV Store

The KV Store is for **persistent plugin state** — data that should survive across sessions (e.g., last selected item, saved search history). It saves data to `.tako/kv.json`.

### Using the KV Store

```go [plugin.go]
func (p *Plugin) OnInit(ctx *tako.Context) error {
    store := ctx.Storage()

    // Save a value
    store.Set("search.last_query", "golang")

    // Read it back
    var lastQuery string
    store.Get("search.last_query", &lastQuery)

    // Delete a key
    store.Delete("search.last_query")
    return nil
}
```

> **Namespacing:** Keys are global. Always prefix your keys with your plugin ID (e.g., `search.history` instead of just `history`) to avoid collisions.

### How It Works (Debouncing)

Writes to the store are **debounced**. Multiple rapid `Set` calls within a 500ms window are batched into a single disk write. The write uses an atomic rename (`write temp file → os.Rename`) to prevent corruption. 

On app shutdown, the store guarantees a final synchronous flush to disk, ensuring data is never lost.
