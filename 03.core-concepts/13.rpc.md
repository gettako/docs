## What is the RPC Bus?

While the **Event Bus** is designed for *fire-and-forget* asynchronous events, the **RPC Bus** is designed for **synchronous, request-response** communication between plugins.

Use the RPC Bus when Plugin A needs data from Plugin B and must wait for the response before proceeding.

## Fluent API

The Tako framework provides a highly expressive, chainable Fluent API for both routing (providing an endpoint) and calling (requesting an endpoint).

### 1. Registering an Endpoint (Router)

To expose a service, you define an RPC route using `ctx.RPC().Route()`. You can enforce execution timeouts using `.Timeout()`.

```go [plugin_b.go]
// Register a route to calculate user score
ctx.RPC().Route("user.calculate_score").
    Timeout(2 * time.Second). // Automatically cancels context if it takes > 2s
    Handle(func(ctx context.Context, req contracts.RPCRequest) (contracts.RPCResponse, error) {
        
        userID, ok := req.Payload.(int)
        if !ok {
            return contracts.RPCResponse{}, errors.New("invalid payload")
        }
        
        score := database.GetScore(userID)
        
        return contracts.RPCResponse{Data: score}, nil
    })
```

### 2. Calling an Endpoint (Caller)

To consume a service from another plugin, use `ctx.RPC().Call()`. 
You can easily pass payloads and even configure automatic **Retries** in case the remote service temporarily fails!

```go [plugin_a.go]
// Call the endpoint, pass payload, and retry up to 3 times if it fails
resp, err := ctx.RPC().Call("user.calculate_score").
    WithPayload(42).
    WithContext(context.Background()).
    Retry(3). // Automatically retries up to 3 times on failure
    Await()   // Blocks until response or final error is received

if err != nil {
    log.Printf("Failed to get score: %v", err)
    return
}

score := resp.Data.(int)
fmt.Printf("User 42 has score: %d\n", score)
```

## When to use RPC vs Event Bus?

- Use **RPC (`ctx.RPC()`)** when you need a direct **Return Value** (e.g., fetching a database record, calculating a hash).
- Use **Event Bus (`ctx.Event()`)** when you just want to announce something happened and don't care who listens or what they return (e.g., `user.logged_in`, `file.saved`).
