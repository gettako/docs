## Registering a Theme

You can register a theme by providing a map of tokens to color values. We recommend using consistent palette token names (like `base`, `text`, `primary`, `error`) across your themes to ensure cross-theme compatibility.

```go [lifecycle.go]
func (p *Plugin) OnInit(ctx *tako.Context) error {
    ctx.Theme().Register("catppuccin-mocha", map[string]string{
        "base":      "#1e1e2e",
        "text":      "#cdd6f4",
        "primary":   "#cba6f7", // Mauve
        "secondary": "#89b4fa", // Blue
        "error":     "#f38ba8", // Red
    })
    
    // Register another theme
    ctx.Theme().Register("light-mode", map[string]string{
        "base":      "#ffffff",
        "text":      "#000000",
        "primary":   "#0055ff",
        "secondary": "#555555",
        "error":     "#ff0000",
    })
    
    // Switch to this theme
    ctx.Theme().Use("catppuccin-mocha")
    return nil
}
```

## Using the Theme

In your UI components, ask the Theme engine for the color token. This guarantees your component will seamlessly blend into whatever theme the host application is currently using.

```go [layout.go]
func Render(ctx *tako.Context) string {
    primaryHex := ctx.Theme().Get("primary")
    
    // Example using Lipgloss (Bubble Tea)
    style := lipgloss.NewStyle().Foreground(lipgloss.Color(primaryHex))
    return style.Render("Hello Tako!")
}
```

## Dynamic Theme Switching

When `ctx.Theme().Use("theme-name")` is called, Tako automatically emits a `"theme:changed"` event. If you are using the Bubble Tea adapter, you can listen to this event to trigger a full re-render of the application, resulting in instant, application-wide theme switching.
