## Registering Dictionaries

You can register language dictionaries tied to a specific locale code.

```go [lifecycle.go]
func (p *Plugin) OnInit(ctx *tako.Context) error {
    ctx.Lang().Register("id_ID", map[string]string{
        "greeting": "Halo, Dunia!",
        "error.not_found": "File {} tidak ditemukan.",
    })
    
    ctx.Lang().Register("en_US", map[string]string{
        "greeting": "Hello, World!",
        "error.not_found": "File {} was not found.",
    })
    
    // Set the active locale
    ctx.Lang().SetLocale("id_ID")
    return nil
}
```

## Translating Strings

To translate a string in your views, use the `T` method. It supports positional string replacement using `{}` placeholders. The placeholders are replaced sequentially with the provided arguments.

```go [layout.go]
// Returns "Halo, Dunia!"
msg := ctx.Lang().T("greeting")

// Returns "File config.json tidak ditemukan."
err := ctx.Lang().T("error.not_found", "config.json")
```

## Fallback Chain

Tako uses `en` as the ultimate fallback language.
1. If a key is missing in the active locale, Tako will look for it in the `en` dictionary.
2. If it is still not found, Tako will return the translation key itself (e.g., returning `"error.not_found"`).

## Reacting to Locale Changes

When `SetLocale()` is called, the framework emits a `contracts.EventLangChanged` event via the event bus. Plugins can listen to this event to update their UI or re-render components with the new language.
