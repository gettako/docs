The event bus is fire-and-forget. When a provider needs an answer — "does inventory have enough stock?" or "what is the current user's role?" — use the RPC bus. One provider
registers a route; any other provider calls it and blocks until a response arrives.

## Registering a Route

```go [providers/inventory/provider.go]
func (p *InventoryProvider) Boot(app *foundation.Application) error {
    route := app.RPC().Route("inventory:check_stock")
    route.Timeout(2 * time.Second)      // Call fails if handler takes longer than 2s
    route.Guard(p.requireAuthenticated) // Reject callers that don't meet conditions
    route.Handle(func(req contracts.RPCRequest) contracts.RPCResponse {
        sku, ok := req.Payload.(string)
        if !ok {
            return contracts.RPCResponse{Error: errors.New("payload must be a SKU string")}
        }

        qty := p.stock[sku]
        return contracts.RPCResponse{
            Data: StockResult{
                SKU:      sku,
                Quantity: qty,
                InStock:  qty > 0,
            },
        }
    })
    return nil
}
```

**Route naming convention:** `provider_name:action` — makes the owning provider clear at every call site.

One handler per route. Registering a second handler for the same route replaces the first (with a warning logged).

## Guards

A guard is a function that can reject a call before the handler runs:

```go [provider.go]
func (p *InventoryProvider) requireAuthenticated(req contracts.RPCRequest) (bool, error) {
    if req.CallerID == "" {
        return false, errors.New("unauthenticated caller")
    }
    return true, nil
}
```

Multiple guards are composed in order — all must pass. Guards return `(bool, error)`; the first `false` short-circuits with an error response to the caller.

## Calling a Route

```go [providers/checkout/provider.go]
func (p *CheckoutProvider) validateStock(ctx *tako.Context, sku string, qty int) error {
    call := ctx.RPC().Call("inventory:check_stock")
    call.WithPayload(sku)
    call.WithContext(ctx.Context()) // Propagates cancellation
    call.Retry(3)                   // Retry up to 3 times on transient failure
    resp := call.Await()            // Blocks until response or timeout

    if resp.Error != nil {
        return fmt.Errorf("stock check failed: %w", resp.Error)
    }

    result := resp.Data.(StockResult)
    if !result.InStock {
        return fmt.Errorf("SKU %s is out of stock", sku)
    }
    if result.Quantity < qty {
        return fmt.Errorf("only %d units of %s available", result.Quantity, sku)
    }
    return nil
}
```

`Await` blocks the calling goroutine. For concurrent calls, wrap in a goroutine or use `AwaitAsync`.

## Async Calling

For non-blocking calls:

```go [provider.go]
func (p *DashboardProvider) refreshAll(ctx *tako.Context) {
    // Fire all three calls concurrently
    stockCall := ctx.RPC().Call("inventory:check_stock")
    stockCall.WithPayload("SKU-001")
    stockCall.WithContext(ctx.Context())
    stockCh := stockCall.AwaitAsync() // Returns <-chan contracts.RPCResponse

    priceCall := ctx.RPC().Call("catalog:get_price")
    priceCall.WithPayload("SKU-001")
    priceCall.WithContext(ctx.Context())
    priceCh := priceCall.AwaitAsync()

    // Collect results
    stockResp := <-stockCh
    priceResp := <-priceCh

    if stockResp.Error == nil && priceResp.Error == nil {
        p.updateDisplay(stockResp.Data.(StockResult), priceResp.Data.(float64))
    }
}
```

## RPC vs Events

| RPC Bus                              | Event Bus                          |
|--------------------------------------|------------------------------------|
| One caller, one handler              | One publisher, many subscribers    |
| Returns a response                   | Fire-and-forget                    |
| Supports timeout + retry             | No built-in timeout                |
| Use for: data queries, service calls | Use for: notifications, broadcasts |

A good rule of thumb: if you need data back, use RPC. If you're announcing something happened, use events.

## Introspection

```bash [terminal]
go run . route:list
```

Lists all registered RPC routes, their owning providers, and guard/timeout configuration. Useful for understanding inter-provider dependencies without reading source.

::tip
Don't use RPC where state is more appropriate. If multiple providers need the same data, store it in the state manager and let them read it directly — no RPC round-trip. Use RPC
when the data is owned by a specific provider and requires business logic to produce (like a stock check that validates permissions), not for simple reads of shared state.
::
