For commands with multiple flags, aliases, and default values, wiring up Go's `flag` package manually is tedious. The `CommandBuilder` provides a fluent API to declare your option
schema. Tako handles the parsing, validation, and help text generation automatically.

## The Configure Method

Implement `Configure(*cli.CommandBuilder)` on your command. Tako calls this during registration to build the schema.

```go [commands/export.go]
package commands

import "gettako.dev/tako/cli"

type ExportCommand struct{}

func (c *ExportCommand) Name() string        { return "export" }
func (c *ExportCommand) Description() string { return "Export application data to a file" }

func (c *ExportCommand) Configure(builder *cli.CommandBuilder) {
	builder.AddOption("format").
		Alias("f").
		AsString().
		Default("csv").
		Description("Output format (csv, json, xml)")

	builder.AddOption("compress").
		Alias("c").
		AsBool().
		Description("Compress the output file with gzip")

	builder.AddOption("workers").
		AsString().
		Default("4").
		Description("Number of concurrent workers")
}

func (c *ExportCommand) Execute(ctx *cli.Context, args []string) error {
	format := ctx.Flag("format")         // "csv" by default
	compress := ctx.BoolFlag("compress") // false by default
	workers := ctx.Flag("workers")       // "4" by default

	ctx.Writef("Exporting data as %s (compress: %v) using %s workers...\n", format, compress, workers)
	return nil
}
```

If you change `.Default("csv")` to `.Default("json")`, both the runtime behavior and the `--help` output update instantly.

## Option Types

### AsBool()

A flag that takes no value. Its presence means `true`.

```go
builder.AddOption("dry-run").
Alias("n").
AsBool().
Description("Simulate the action without making changes")
```

Usage: `myapp run --dry-run`

### AsString()

A flag that requires a value. Providing the flag without a value triggers a parse error.

```go
builder.AddOption("target").
Alias("t").
AsString().
Default("production").
Description("Deployment target environment")
```

Usage: `myapp run --target=staging`

### AsOptional()

A flag that can accept an optional value.

```go
builder.AddOption("color").
AsOptional().
Default("auto").
Description("Colorize output (auto, always, never)")
```

| Invocation      | `ctx.Flag("color")`     |
|-----------------|-------------------------|
| (omitted)       | `""`                    |
| `--color`       | `"auto"` (default used) |
| `--color=never` | `"never"`               |

## Builder API Reference

| Method             | Purpose                                                                          |
|--------------------|----------------------------------------------------------------------------------|
| `AddOption(name)`  | Starts a new option definition                                                   |
| `Alias(char)`      | Registers a single-character shorthand (e.g., `f` for `-f`)                      |
| `AsString()`       | Option requires a string value                                                   |
| `AsBool()`         | Option is a boolean toggle                                                       |
| `AsOptional()`     | Option accepts an optional string value                                          |
| `Default(val)`     | Default value if the flag is provided without a value, or omitted for `AsString` |
| `Description(txt)` | Help text displayed in `myapp command --help`                                    |

::warning
Option names must be unique within a command. Registering duplicate names or aliases causes a panic at boot time.
::

::tip
You don't have to choose between the fluent builder and signatures. They are functionally identical under the hood. Use the builder when you have long descriptions or complex logic
to conditionally add flags; use signatures for compact, readable definitions.
::
