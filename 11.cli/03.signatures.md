For commands with straightforward flags, the fluent builder can feel like boilerplate. Signatures let you encode your entire option schema in a single string. Tako parses it at
boot and builds the exact same option schema you would get from the `CommandBuilder`.

## The SignatureProvider Interface

Signatures are **optional**. Commands that need them implement the `SignatureProvider` interface — a separate, optional interface, not part of the core `Command` interface.
Commands without signatures require no stub.

```go
// Optional — only implement this if you want signature-style flag declaration.
type SignatureProvider interface {
    Signature() string
}
```

Implement it on your command:

```go [commands/logs.go]
package commands

import "gettako.dev/tako/internal/console/cli"

type LogsCommand struct{}

func (c *LogsCommand) Name() string        { return "logs" }
func (c *LogsCommand) Description() string { return "View application logs" }

// Signature is optional — only needed when using the signature flag syntax.
func (c *LogsCommand) Signature() string {
    return "{--f|follow : Stream new logs as they arrive} {--l|level=info : Minimum severity level} {--n|lines=50 : Lines of history to show}"
}

func (c *LogsCommand) Execute(ctx *cli.Context, args []string) error {
    follow := ctx.BoolFlag("follow")
    level := ctx.Flag("level")
    lines := ctx.Flag("lines")

    ctx.Writef("Fetching last %s logs at %s level (follow: %v)\n", lines, level, follow)
    return nil
}
```

The signature `{--l|level=info : Minimum severity level}` is identical to:

```go
builder.AddOption("level").Alias("l").AsString().Default("info").Description("Minimum severity level")
```

## Syntax Reference

Each option is wrapped in curly braces: `{--name|alias=default : Description}`

### The `--` Prefix

Marks the option as a flag rather than a positional argument (positional arguments are not currently supported by signatures).
`{--verbose}`

### The `|` Pipe

Separates the alias from the full name. The alias always comes first.
`{--f|format}` creates `-f` and `--format`.

### The `=` Equals

Determines the option type and default value.

| Syntax           | Inferred Type               | `ctx` Access                        |
|------------------|-----------------------------|-------------------------------------|
| `{--verbose}`    | `AsBool()`                  | `ctx.BoolFlag("verbose")`           |
| `{--format=csv}` | `AsString().Default("csv")` | `ctx.Flag("format")` → `"csv"`      |
| `{--color=}`     | `AsOptional()`              | `ctx.Flag("color")` → `""` or value |

### The `:` Colon

Separates the flag definition from the help text description.

`{--force : Skip confirmation prompts}`

::warning
The spaces around the colon are required (` : `). This prevents ambiguity with colons inside default values like `{--url=http://localhost:8080}`.
::

## Mixing Signatures and Builders

If a command defines both `Signature()` and `Configure()`, Tako parses the signature first, then passes the resulting builder to `Configure()`. This lets you use the compact
signature for simple flags and the builder for complex ones:

```go [commands/hybrid.go]
func (c *HybridCommand) Signature() string {
    return "{--q|quiet : Suppress output} {--c|compress : Compress output}"
}

func (c *HybridCommand) Configure(builder *cli.CommandBuilder) {
    builder.AddOption("format").
        Alias("f").
        AsString().
        Default("json").
        Description("Output format. Supported values:\n  - json: NDJSON stream\n  - csv: Comma separated\n  - text: Human readable")
}
```

If both define the same option name, the `Configure()` builder wins and overwrites the signature definition.

## Parsing Errors

Syntax errors in your signature (like missing an `=` for a default value, or reusing an alias) cause an immediate panic when the application boots:

```
panic: invalid signature token "{--format csv}": missing '=' for default value
```

::tip
If your command has more than 3-4 options, or if the descriptions are long, stick to the `Configure()` builder. Signatures are fantastic for brevity, but a 300-character signature
string is harder to read than a few fluent method chains.
::
