Out of the box, Tako provides several powerful CLI commands to assist with your development and deployment workflows. You don't need to write any code to use these; they are
automatically registered by the framework's core service providers.

## Available Commands

### `list`

The `list` command displays a beautifully formatted list of all commands currently registered in your application's Service Container, along with their descriptions.

```bash
go run main.go list
```

This is incredibly useful for discovering what commands are available (especially if you have installed third-party Tako packages) or reminding yourself of the specific signature
required to run a custom command you wrote months ago.

### `build`

The `build` command compiles your Tako application for production.

```bash
go run main.go build
```

Under the hood, this command executes `go build` with specific optimizations (like the `prod` build tag) to ensure development dependencies (like the Hot-Reloading Watcher and
Profiler Server) are completely stripped from your final binary. This guarantees your production binary is as small and fast as possible.

You can also specify a custom output path or force a full rebuild:

```bash
go run main.go build dist/my-app-linux --force
```

*(By default, binaries are output to the `dist/` directory).*

### `inspect`

The `inspect` command is a powerful developer tool that connects to the live data stream of a running Tako application.

```bash
go run main.go inspect
```

As detailed in the [Developer Tools](/testing-and-debugging/developer-tools) documentation, this command reads the Unix socket exposed by the Profiler Server and outputs real-time
metrics (FPS, Memory, Uptime, Goroutines).

## Future Commands

Tako is actively evolving. In upcoming releases, you can expect the following built-in commands to be added to the core framework:

- **`doctor`**: Scans your application's architecture (Checking Service Providers, Configuration, and Storage permissions) and reports any potential misconfigurations or missing
  dependencies.
- **`log:viewer`**: A dedicated TUI screen for streaming and filtering your application's `.tako.log` file in real-time, complete with syntax highlighting for JSON and stack
  traces.
- **`cache:clean`**: Instantly flushes the local application cache.
- **`make:*` generators**: A suite of commands (e.g., `make:provider`, `make:command`, `make:view`) to rapidly scaffold boilerplate code, drastically speeding up development time.
