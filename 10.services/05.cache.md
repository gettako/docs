In a long-running TUI application, hitting the same external API on every keypress or re-render is wasteful and risks rate limiting. Tako's built-in Cache provides a TTL-based file
cache with zero external dependencies. Cached values survive application restarts and expired entries are automatically discarded on load.

## Interface

```go [contracts/cache.go]
type Cache interface {
    Has(key string) bool
    Get(key string, ptr any) bool
    Set(key string, value any, ttl time.Duration) error

    // Remember is the primary cache-aside entry point.
    Remember(key string, ttl time.Duration, fn func() (any, error)) (any, error)

    Forget(key string) error
    Clear() error
    Flush() error
}
```

## Usage

Access the cache via `ctx.Cache()` from any provider:

```go [providers/catalog/provider.go]
func (p *CatalogProvider) Boot(app *foundation.Application) error {
    ctx := app.Context()

    data, err := ctx.Cache().Remember("catalog:products", 5*time.Minute, func() (any, error) {
        return p.api.FetchProducts(ctx.Context)
    })
    if err != nil {
        ctx.Logger().Error("failed to load catalog", "err", err)
        return err
    }

    products := data.([]Product)
    ctx.State().Set("catalog:products", products)
    return nil
}
```

The first call fetches from the API and stores the result. Every subsequent call within 5 minutes returns the cached value immediately — without touching the network.

## Manual Get and Set

For more granular control, use `Get` and `Set` directly:

```go [providers/profile/provider.go]
func (p *ProfileProvider) loadProfile(ctx *tako.Context, userID string) {
    key := "profile:" + userID

    var profile UserProfile
    if ctx.Cache().Get(key, &profile) {
        p.profile = profile
        return
    }

    // Cache miss — fetch from API.
    profile, err := p.api.GetProfile(userID)
    if err != nil {
        ctx.Logger().Error("failed to fetch profile", "err", err)
        return
    }

    _ = ctx.Cache().Set(key, profile, 10*time.Minute)
    p.profile = profile
}
```

## TTL Values

| TTL             | Use For                                                       |
|-----------------|---------------------------------------------------------------|
| `0`             | Never expires (e.g. static configuration loaded once at boot) |
| `1*time.Minute` | Rapidly changing data (notifications, unread counts)          |
| `5*time.Minute` | Semi-static data (catalog, product list)                      |
| `1*time.Hour`   | Slow-changing data (user profile, permissions)                |
| `24*time.Hour`  | Near-static data (country list, static references)            |

## Invalidation

Remove a single key when you know the data has changed (e.g., after a successful mutation):

```go [providers/orders/provider.go]
func (p *OrderProvider) onOrderPlaced(e contracts.Event) {
    // Invalidate the orders cache so the next read fetches fresh data.
    _ = p.ctx.Cache().Forget("orders:active")
}
```

To wipe everything at once (e.g., on logout):

```go
_ = ctx.Cache().Clear()
```

## Persistence & Storage

The cache stores one file per key, sharded using SHA-256 to prevent filesystem limits and path traversal attacks. Files are stored at:

```
.tako/cache/<hash[0:2]>/<hash[2:4]>/<hash>
```

Writes are **synchronous** ($O(1)$) and only affect the specific key. A lightweight background Garbage Collector automatically scans the directory and deletes expired files every 5
minutes.

::warning
The cache file is not encrypted. Do not store sensitive data (tokens, passwords, PII) in the cache — use [Secure Storage](/state-management/secure-storage) for those.
::

## Stampede Prevention

When many goroutines call `Remember` for the **same missing key** at the same time (e.g., a TUI with 5 components all booting simultaneously), only **one** goroutine actually calls
your `fn`. The other goroutines wait for the result and share it. This prevents the "cache stampede" problem where multiple API calls are made for the same data.

```go
// All 5 providers call this simultaneously on boot.
// Only 1 actual HTTP request is made.
data, err := ctx.Cache().Remember("github:stats", time.Hour, func() (any, error) {
    return fetchGitHubStats()
})
```

::tip
Combine Cache with Cron for a "warm cache" pattern: use `ctx.Jobs().Cron("*/5 * * * *", ...)` to proactively refresh the cache in the background every 5 minutes, so foreground
reads are always instant.
::
