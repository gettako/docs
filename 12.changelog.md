## [0.1.0] - 2026-05-15

### Added
- **Core Engine**: Initial release of the robust `App` container and `Context` lifecycle manager.
- **Event Bus**: High-performance, concurrent-safe event propagation system for decoupled inter-component communication.
- **Hook System**: Extensible hook infrastructure (`PreRun`, `PostRun`, `PreRender`, `PostRender`) for injecting middleware logic.
- **Overlay Manager**: Complete Z-index driven layer management system with stacking context and guard capabilities for modal dialogs.
- **Plugin Architecture**: Modular plugin interface to drop-in functionality seamlessly without touching core components.
- **Developer Tools**: Powerful built-in DevTools including an Inspector, Profiler, and runtime Hot Reload mechanisms.
- **Example App**: Included a fully functional mini-app example to demonstrate framework capabilities out-of-the-box.
