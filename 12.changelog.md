The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased] - Next Major Version (v2.0.0)

The Tako framework is currently undergoing a massive architectural rewrite from the ground up to improve scalability, maintainability, and Developer Experience (DX).

### Added
- **Service Container (IoC)**: A fully thread-safe dependency injection container (`contracts.Container`) inspired by Laravel.
- **Service Providers**: A robust boot lifecycle (`Register` and `Boot`) for modular architecture.
- **Console Kernel**: A declarative, signature-based CLI routing system (`app.Commands()`) that automatically parses arguments and options.
- **TUI Kernel**: A new underlying engine that abstracts away raw `tea.Model` boilerplate using the `contracts.View` and `contracts.Router` systems.
- **Built-in Watcher**: A hot-reloading file watcher with *Terminal Rescue* capabilities to prevent broken terminal states on crashes.
- **Live Profiler**: An IPC server streaming real-time metrics (FPS, Memory, Goroutines) over a Unix socket, accessible via the `inspect` command.
- **Event Bus**: A highly optimized event dispatcher with `O(1)` listener cancellation to prevent memory leaks in dynamic UIs.
- **Mouse Manager**: Native integration with BubbleZone to handle complex TUI mouse clicks (`OnZoneClick`).
- **Multi-channel Logger**: Automatic file rotation (via Lumberjack) and driver-extensible logging.

### Changed
- The entire `core` package has been dismantled and strictly separated into `contracts` (interfaces), `internal` (concrete implementations), and `pkg` (wrappers).
- Routing is now stack-based, allowing for nested layouts and modal overlays.
- Removed hardcoded terminal interactions in favor of a provider-based boot sequence.

### Removed
- `tako.Config` has been replaced by `contracts.ConfigRepository`.
- Previous unstable RPC and Scheduler implementations have been temporarily removed pending a rewrite for v2.
