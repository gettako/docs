Once you are familiar with the concepts of the Tako framework, you can use this cheat sheet as a quick reference guide to remember specific syntax, method names, and formatting tags without reading through the full documentation.

## Application & Container

**Creating the App:**
```go
app := tako.NewApp()
tako.Run(app)
```

**Binding Services:**
*(Typically done inside a Service Provider's `Register` method)*
```go
// Singleton: Shared instance across the entire app
app.Singleton("db", func(app contracts.Application) *Database { return &Database{} })

// Transient: Fresh instance every time it's resolved
app.Bind("user", func(app contracts.Application) *User { return &User{} })

// Instance: Bind an already constructed object directly
app.Instance("config", myConfigObject)
```

**Resolving Services:**
```go
// Using generic helper (Recommended for type safety)
db, err := contracts.Resolve[*Database](app, "db")

// Manual reflection
obj, err := app.Make("db")
db := obj.(*Database)
```

## Routing

**Defining Routes:**
```go
router := app.TUI().Router()

// Basic Route
router.Route("home", func() contracts.View { return &components.Home{} })

// Route with Layout (Persistent wrapping UI)
router.Root(&components.AppLayout{}, func() {
	router.Route("dashboard", func() contracts.View { return &components.Dashboard{} })
	router.Route("settings", func() contracts.View { return &components.Settings{} })
})
```

**Navigation:**
```go
ctx.Router().Navigate("dashboard") // Go to specific route
ctx.Router().Back()                // Pop the current route from the stack
```

## Console Output Formatting

Tako uses inline markup tags so you don't have to memorize ANSI escape codes.

| Tag | Result | Example |
|-----|--------|---------|
| `<info>` | Blue Text | `ctx.Line("<info>Info</>")` |
| `<warn>` | Amber Text | `ctx.Line("<warn>Warning</>")` |
| `<done>` | Green Text | `ctx.Line("<done>Success</>")` |
| `<fail>` | Red Text | `ctx.Line("<fail>Error</>")` |
| `<bold>` | Bold Font | `ctx.Line("<bold>Thick</>")` |
| `<dim>` | Faded Font | `ctx.Line("<dim>Faded</>")` |
| `<fg=hex>` | Custom Color | `ctx.Line("<fg=#ff00ff>Pink</>")` |

## Command Signatures

Tako's signature parser allows you to define complex CLI inputs using a single, readable string.

| Syntax | Type | Example |
|--------|------|---------|
| `{name}` | Required Argument | `user` |
| `{name?}` | Optional Argument | `user` (or nothing) |
| `{name=John}` | Default Argument | `user` (defaults to John) |
| `{--force}` | Boolean Option | `--force` |
| `{--f\|force}` | Option with Alias | `-f` or `--force` |
| `{--queue=}` | String Option | `--queue=emails` |
| `{--id=*}` | Array Option | `--id=1 --id=2` |

**Full Example:**
```go
"make:model {name} {--m|migration : Create a migration file}"
```
